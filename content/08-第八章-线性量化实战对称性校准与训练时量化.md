@@point ① 线性量化：均匀切分映射区间
@@need 要解决什么
线性量化是怎么把浮点值变整数的？公式长什么样？

@@idea 核心思路
**线性（均匀）量化**把浮点区间均匀切分成整数格：

```
q = round(x / s)  ，反量化: x' = q * s
s 是缩放因子（step size）= 浮点范围 / 整数范围
```

关键参数是 **s（step size）**：s 越小，量化越精细、误差越小，但要把浮点范围压缩进有限整数位宽（INT8 只有 256 格）。

完整方案还要配**零点（zero point）** 处理非对称分布：

```
q = round(x / s) + z
x' = (q - z) * s
```

q：整数；x：浮点；s：缩放因子；z：零点。**公式虽然简单，但"浮点范围怎么取"（即怎么定 s）决定了量化误差的生死**——这是根阈值。范围取小了，极端值溢出被截断；取大了，精度平均被稀释。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 记住公式却不知道 s 怎么定 | 工程关键在"范围选择"，不是公式本身 |
| 忽略溢出截断 | 范围外的值被 clamp 到边界，极端离群值会严重拉大误差 |

@@point ② 非对称 vs 对称量化
@@need 要解决什么
线性量化里"对称/非对称"到底差在哪？

@@idea 核心思路
**对称量化（Symmetric）**：浮点区间关于 0 对称，`z=0`，公式简化：

```
q = round(x / s) ，范围: [-a, a]
```

优点：实现简单、硬件友好（不需要零点偏移）；代价：如果数据分布严重偏斜（如 ReLU 后的激活全为正），一半整数区间浪费在负数上。

**非对称量化（Asymmetric）**：记录最小值和最大值：

```
范围: [min, max] → q = round((x - min) / s)
```

优点：区间贴合数据分布，动态范围利用率高；代价：多一个零点偏移 z 要存储与计算。

选择口诀：**权重分布近似对称用对称量化（省事）；激活分布偏斜用非对称量化（省空间）**。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 全网络统一用对称 | 激活（尤其是 ReLU 后）偏斜严重，统一对称会浪费大量位宽 |
| 忽略 z 的计算成本 | 非对称量化在硬件上多一步零点修正，选型要考虑算子支持 |

@@point ③ Thresholding（阈值选择）：设定量化区间
@@need 要解决什么
量化区间的边界（阈值）怎么定才最优？

@@idea 核心思路
**阈值（threshold）**决定浮点→整数的映射区间。常见策略：

1. **Min-Max**：用数据的最小/最大值直接当边界。简单，但**离群值（outliers）**会撑大区间、稀释正常值的精度。
2. **百分位（Percentile）**：取分布的 1%/99% 分位当边界，容忍少量溢出，换正常值更高精度——**实际最常用**。
3. **熵最小化（Entropy）**：选阈值使量化前后的信息熵损失最小（如 TensorRT 的 calibration 核心思想）。

一句话：**阈值本质是"容忍一点溢出，换取更大部分的高精度"**——离群值截断 vs 主流值精度的取舍。这也是对称量化中 Tegra/TensorRT 用"熵校准"的原因。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| Min-Max 一把梭 | 大模型权重常有少量离群值，Min-Max 会把区间撑爆，精度崩 |
| 阈值只看权重不看激活 | 激活分布与权重差异大，需要各自独立校准阈值 |

@@point ④ 校准（Calibration）三法：Min-Max / Entropy / Percentile
@@need 要解决什么
"校准"到底在校什么？三种校准方法怎么选？

@@idea 核心思路
**校准**：用一小批代表数据跑一遍模型，统计每层激活的分布，从而为激活量化确定阈值/范围（s、z）。

三种主流方法：

| 方法 | 思路 | 特点 |
|---|---|---|
| Min-Max | 取激活的最小/最大 | 最简单，怕离群值 |
| Entropy（熵） | 最小化量化前后分布的信息损失 | 精度最好，计算较大 |
| Percentile（百分位） | 取 p% 分位，容忍少量溢出 | 均衡高效，工程常用 |

校准数据要**代表真实推理分布**：选有代表性的样本（如 100~1000 条），跑前向收集每层激活直方图，再按方法求出阈值。校准集质量直接决定量化精度。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 拿训练集校准 | 训练集分布与实际推理输入有偏差，要用贴近线上分布的校准数据 |
| 校准样本太少 | 分布统计不稳，阈值偏差大，最少也要几十上百条代表性样本 |
| 只校准不验证 | 校准后必须用独立验证集评估量化后的精度，回退到上一步调方法 |

@@point ⑤ 训练后量化（PTQ）：最省事的工业路线
@@need 要解决什么
不重新训练直接量化，行不行？

@@idea 核心思路
**训练后量化（Post-Training Quantization, PTQ）**：模型训练完成后，**不需要（完整）重新训练**，只用少量校准数据统计分布即可完成量化。

流程：

```
1. 载入已训练好的 FP32 模型
2. 准备校准数据集（少量）
3. 前向跑校准数据，统计权重/激活分布
4. 计算量化参数（s, z, threshold）
5. 转换 INT/FP16 模型，验证精度
```

**优点**：快速、无需训练资源、对已有模型即插即用。
**代价**：量化误差无法被训练"纠正"，极低位（INT4 及以下）精度损失明显。
**适用**：8bit 场景（INT8/FP16）基本无损，绝大多数生产场景首选 PTQ。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| PTQ 后精度不达预期就直接上 QAT | 先查校准数据与方法，85% 的 PTQ 问题出在"校准不对"，而非"PTQ 不行" |
| 用 PTQ 硬啃 INT4 | 极低位 PTQ 误差大，正常路径是 QAT 或混合精度 |

@@point ⑥ 量化感知训练（QAT）与 STE：让模型"学会"量化
@@need 要解决什么
PTQ 压不动精度时，怎么让训练本身适配量化？

@@idea 核心思路
**量化感知训练（Quantization-Aware Training, QAT）**：在训练/微调过程中**模拟量化**，让权重/激活适应量化误差。

核心难题：量化的 round/clamp 操作**导数几乎处处为0（不可导）**，无法常规反向传播。

解法：**STE（Straight-Through Estimator，直通估计器）**——前向传播走真实量化，反向传播时把量化函数的导数"近似为直通"（当成恒等映射）：

```
前向: q = quantize(x)        # 真实量化
反向: ∂L/∂x ≈ ∂L/∂q          # 导数直通（不乘量化函数的0导数）
```

QAT 流程：

```
1. 插入量化模拟（fake quant）到训练图
2. 用 STE 训练/微调若干轮
3. 收敛后导出真正的量化模型
```

**代价**：需要训练资源与调参；**收益**：INT4 及以下、分布刁钻的模型也能把精度拉回来。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 忘记 STE 的地位 | QAT 能行全靠 STE 解决"不可导"，理解它才算懂 QAT |
| QAT 直接当普通训练 | 量化模拟节点的位置、学习率、时长都有讲究，要按 QAT 规范来 |

@@point ⑦ 混合精度与 Floating16：不只有定点整数
@@need 要解决什么
除了 INT8，量化还有哪些"精度档位"可以混用？

@@idea 核心思路
量化位宽选择是连续的，且可以**混合搭配**：

- **FP16/BF16（半精度浮点）**：最"温柔"的量化，几乎无损、直接翻倍省显存（大模型推理标配）。
- **INT8**：精度/收益平衡之王，工业主流。
- **INT4**：省到极致，必须 QAT/先进算法（GPTQ/AWQ 等）配合。
- **混合精度（Mixed Precision）**：不同层用不同位宽——**敏感层用高精度，冗余层用低位宽**，吸收两者的优点。

**Floating16** 值得一提：浮点低精度比定点简单——不需要范围校准（浮点天然带动态范围），所以 FP16 部署是无脑操作；而 INT 系列的校准知识本章前面的内容正是为此准备。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 一提量化就只想到 INT8 | FP16/BF16 是最低成本的量化（近乎无损），先吃这步红利再说 |
| 混合精度盲目组合 | 各层的"敏感性"要评估（按删除/低bit后的精度影响），不是拍脑袋分配 |

@@point ⑧ 本章小结：线性量化+校准+PTQ/QAT 全图谱
@@need 要解决什么
量化工程的总决策树是什么？

@@idea 核心思路
用一个决策流程图收束本章：

```
选择位宽: FP16开胃 → INT8主流 → INT4拼极限
对称性:   权重偏对称→对称量化；激活偏斜→非对称
阈值:     Min-Max(怕离群) / Percentile(均衡) / Entropy(最优)
校准:     代表数据跑前向 → 统计激活分布 → 定 s/z
量化范式:  PTQ(快,8bit够用) → 精度不够 → QAT+STE(慢,极限位宽)
强化:     混合精度（敏感层高精度,冗余层低位宽）
```

到此量化两章收官。下一章：知识蒸馏 + 全阶段协同优化。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 决策时跳过"实测精度验证" | 每一步（选位宽/校准/范式）都必须验证，最忌"一把梭"后上线 |
| 把 PTQ/QAT 当二选一定死 | PTQ 优先、失效升 QAT 是正解；也可以 PTQ+少量微调折中 |

@@summary
这一章把线性量化的工程细节讲透：

| 主题 | 核心结论 |
|---|---|
| 线性量化 | q=round(x/s)+z，s 由范围决定 |
| 对称vs非对称 | 对称省事/权重用；非对称贴合偏斜分布/激活用 |
| Thresholding | Min-Max怕离群 / Percentile 均衡 / Entropy 最优 |
| 校准 | 代表数据统计分布，定 s/z；三类方法按精度算力取舍 |
| PTQ | 训练后直接量化，8bit 主流，靠校准控制误差 |
| QAT | 训练中模拟量化，STE 解决不可导，极限位宽用 |
| 混合/FP16 | FP16 近乎无损低成本；混合精度按层敏感性分配 |

一句话记住本章：**线性量化就是 q=round(x/s)+z，一切精度悬念都在"范围/阈值怎么选"——对称量化适合权重、非对称贴合偏斜的激活；阈值三法（Min-Max 怕离群值、Percentile 均衡实用、Entropy 精度最优）要靠校准数据统计分布来定；范式上 PTQ 训练后直接量化是 8bit 工业主流，压不动精度就上 QAT 用 STE 绕过量化不可导问题在训练中适配；FP16 是最低成本量化，混合精度则按每层的敏感性分配位宽。**
