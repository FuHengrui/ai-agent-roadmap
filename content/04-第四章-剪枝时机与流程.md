@@why 这一章在解决什么问题
上一章学会了"剪什么"，这一章回答**"什么时候剪"**——训练前、训练中还是训练后剪？时机直接决定剪枝的效果与成本。同时把**剪枝的标准流程**串起来：从训练基准模型，到算重要性、生成掩码、剪掉、微调，每一步都有讲究。错过/做错时机，往往就是"剪完精度崩了"的根源。

@@map 上一章→本章→下一章
上一章建立了剪枝的定义、收益与两种粒度。**本章聚焦"何时剪"与"怎么剪"：三种剪枝时机 + 剪枝六步标准流程**。下一章深入非结构化剪枝的工程细节（掩码、稀疏度、动态网络手术），并给出实战建议。

@@point ① 三种剪枝时机：训练前、训练中、训练后
@@need 要解决什么
剪枝可以在训练的哪个阶段进行？各有什么特点？

@@idea 核心思路
剪枝有两个概念性时机维度，讲义将其归纳为三类：

- **训练前剪枝（Pre-training）**：初始化后就剪，训一个稀疏模型（如 Lottery Ticket Hypothesis、随机稀疏初始化）。省了整轮训练成本，但稀疏结构难找。
- **训练中剪枝（Dynamic / During training）**：训练过程中边学边剪，动态调整掩码（如 dynamic network surgery）。结构与权重共同优化，效果通常更好，但实现复杂。
- **训练后剪枝（Post-training）**：先把基准模型训到收敛，再剪枝（必要时微调）。**流程最简单、工业界主流**。

工业现实：LLM 时代"训练后剪枝 + 轻量微调"最常用——因为基础模型很贵，不想为剪枝重训一遍。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为剪枝只能训练后做 | 训练中动态剪枝效果可能更好，只是工程复杂；选型看成本与收益 |
| 训练后剪枝不做微调 | 剪完直接上线的精度往往不理想，常见补救是短时微调补偿 |

@@point ② 训练前剪枝：稀疏初始化思路
@@need 要解决什么
"先剪后训"可行吗？它的价值与瓶颈在哪？

@@idea 核心思路
训练前剪枝（或"稀疏训练"）的思路：

```
1. 初始化网络（可能随机初始化）
2. 先按某种规则确定要保留的连接（固定掩码）
3. 只对保留的连接做训练
4. 从头到尾都保持稀疏结构
```

**价值**：整条训练链路都在小模型上进行，训练成本大幅下降。
**瓶颈**：初始阶段就确定"哪些连接重要"非常难——重要性是训练过程塑造出来的，先验很难猜中；错过关键连接可能导致精度损失。Lottery Ticket 假设正是研究"怎么找值得保留的子网络"。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 随机固定掩码硬训 | 随机稀疏结构大概率不是好彩票，工程上要基于已有知识做初始化选择 |
| 忽视"子网络可训性"问题 | 训练前剪枝的难点不是省多少，而是"剪掉后还能不能训好" |

@@point ③ 训练中剪枝：动态调整掩码
@@need 要解决什么
边训练边剪是怎么运作的？为什么效果可能更好？

@@idea 核心思路
训练中剪枝（Dynamic Pruning）把"剪枝"与"训练"融合：

```
每个训练周期：
  1. 正常前向/反向传播更新权重
  2. 周期性评估权重重要性
  3. 剪掉不重要的连接（置0）
  4. 允许重要的连接"复活"（掩码动态更新）
  → 结构与权重一起优化
```

关键特点：**掩码不固定**。某些被剪的连接如果在后续训练中变得重要，可以重新激活——不像训练后剪枝"一刀切死"。代价是实现复杂、训练开销略增，但往往能在同等稀疏度下保住更好精度。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 更新掩码过于频繁 | 每个 batch 都重新评估重要性会拖慢训练，常以 epoch 为单位动态更新 |
| 剪枝幅度一次拉满 | 动态剪枝通常"渐进"进行（逐步提高稀疏度），一步到位容易破坏训练 |

@@point ④ 训练后剪枝：工业界的主流选择
@@need 要解决什么
为什么生产环境几乎都选训练后剪枝？

@@idea 核心思路
训练后剪枝（Post-training Pruning）流程极简：

```
1. 训练（或复用已开源）一个收敛的基准模型
2. 按重要性评估剪掉部分连接/通道
3. 保存稀疏模型（稀疏格式）
4. 可选：用少量数据微调恢复精度
```

**为什么主流**：基础大模型的训练成本极高（GPU 万卡时级别），没人肯为剪枝重训；而"训好的模型直接剪+短微调"成本低、见效快、风险小。稀疏模型库（如 LLM.Pruner、SparseGPT 类工具）正是基于这条路。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为训练后剪枝必须从头训模型 | 完全不需要，开源预训练模型直接可用，这正是它工业可用的关键 |
| 忽略微调阶段存在 | 直接剪完不微调，精度往往有损失；微调（即使几轮）能把损失拉回来 |

@@point ⑤ 剪枝的标准流程：六步走
@@need 要解决什么
无论哪种时机，剪枝的通用动作是什么？

@@idea 核心思路
讲义给出了剪枝的统一流程骨架（以训练后剪枝为准）：

```
① 训练基准模型（或载入预训练权重）
② 选择剪枝粒度（连接级/通道级）
③ 给每个参数计算重要性分数
④ 依据策略生成掩码（保留/删除标记）
⑤ 置0删除并保存为稀疏模型
⑥ 对稀疏模型微调（补偿精度损失）
```

其中 **③重要性计算**与**④掩码生成**是算法核心，后续章节专门展开；**⑥微调**是工程上不可省略的"收尾"。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 跳过微调以为省事 | 微调是恢复精度的关键，缺失会导致上线精度不达标 |
| 流程顺序搞反 | 必须先有收敛模型再剪，不能"边训边剪边评估"乱序操作（除非用动态剪枝） |

@@point ⑥ 剪掉后怎么恢复精度：微调（Fine-tuning）
@@need 要解决什么
剪枝后的模型精度掉了，怎么补回来？

@@idea 核心思路
**微调（Fine-tuning）** 是剪枝后的标准补偿手段：

- 用训练数据（或代表性子集）继续训练被剪模型若干轮。
- 让剩余参数"重新适应"被剪掉的结构，重新分配表达。
- 如果用了掩码锁定，则掩码之外的剩余权重参与更新。

要点：
- 学习率通常比原始训练更小（防破坏已有知识）。
- 数据量不必巨大，但要有代表性。
- 高稀疏度时，必要时重复"剪枝→微调"多轮（iterative pruning）效果更好。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 微调学习率设得过大 | 会破坏剪枝保留的结构，甚至比不微调更差 |
| 只微调一轮就放弃 | 高稀疏度可迭代剪枝：剪→微调→再剪→再微调，逐步收敛到目标 |

@@point ⑦ 剪枝的一个常见误区：只看"剪掉多少"
@@need 要解决什么
评估剪枝效果好坏的姿势是什么？

@@idea 核心思路
"剪得越多越好"是常见误区。评估剪枝要综合四件事：

1. **稀疏度**：剪掉比例（如 80%）。
2. **精度保留**：剪后 vs 原模型在验证集上的精度差。
3. **实际加速**：真实硬件上的推理延时/吞吐（不是理论 FLOPS）。
4. **实际体积**：稀疏存储后文件大小。

只有"精度保住了 + 实测变快变小"才算成功。只看稀疏度，或只报理论加速比，都容易自欺欺人。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 用理论加速比代替实测 | 无稀疏算子的硬件上，非结构化剪枝实测可能几乎不加速 |
| 精度评估只用训练集 | 用训练集评估会"自我感觉良好"，必须在验证/测试集上验收 |

@@point ⑧ 本章小结：时机判断 + 流程全览
@@need 要解决什么
学完本章，剪枝的"时间轴"和"动作清单"是什么？

@@idea 核心思路
用时间轴总结本章：

```
训练前剪枝 → 早期定稀疏结构省训练，但难猜哪些连接重要
训练中剪枝 → 掩码动态进化，结构与权重共同优化，效果优但复杂
训练后剪枝 → 训好再剪+微调，流程最简单，工业界主流
通用流程 → 基准模型 → 选粒度 → 算重要性 → 生成掩码 → 置0保存 → 微调恢复
评估标准 → 稀疏度 + 精度保留 + 实测加速 + 实际体积，缺一不可
```

下一章进入"算重要性→生成掩码"的核心：非结构化剪枝的掩码机制与稀疏度选择。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 把时机与流程割裂记忆 | 时机决定起点（哪来的模型），流程是通用动作，两者配合使用 |
| 忘记评估第二把尺子 | 剪枝最终要看实测加速，与第一章"理论加速比"呼应但必须实测验证 |

@@summary
这一章解决了"什么时候剪、怎么剪"：

| 时机 | 特点 | 适用 |
|---|---|---|
| 训练前剪枝 | 稀疏训练成本低，但稀疏结构难提前确定 | 学术研究/彩票假设 |
| 训练中剪枝 | 掩码动态更新，效果优，实现复杂 | 追求极致压缩 |
| 训练后剪枝 | 训好再剪+微调，简单可靠 | 工业界主流 |

标准流程：基准模型 → 选粒度 → 算重要性 → 生成掩码 → 置0保存 → 微调恢复。
评估标准：稀疏度 + 精度 + 实测加速 + 实际体积，四维综合。

一句话记住本章：**剪枝三时机——训练前（省成本难选结构）、训练中（掩码动态进化效果最好）、训练后（训好再剪+微调，工业界主流）；无论哪种时机都走"基准模型→算重要性→生成掩码→置0保存→微调恢复"的流程，且验收必须看稀疏度+精度+实测加速+实际体积四件事，别被"剪得多"忽悠。**
