@@point ① 自然语言处理（NLP）是什么
@@need 要解决什么
整天说"AI 会聊天、会翻译"，背后处理语言的技术到底是什么？

@@idea 核心思路
**自然语言处理（Natural Language Processing，NLP）** 是让计算机理解、处理和生成人类语言（中文、英文等）的一门学科，横跨计算机科学、语言学和人工智能。

核心问题是解决"人机对话鸿沟"：人用**有歧义、不完整、依赖语境**的自然语言表达，计算机只会**精确、无歧义**的数字运算。NLP 要做的事就是在这两者之间架桥：

- 让机器**理解**：从文本里抽取信息（情绪、实体、关系）。
- 让机器**生成**：根据意图写文章、做翻译、回消息。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为 NLP = 聊天机器人 | 聊天只是生成类任务的一个应用；理解、抽取、分类、翻译都是 NLP，覆盖面远不止对话 |
| 以为 NLP 就是"把字变成向量" | 向量化只是表示层，理解还要靠模型建模词与词、句与句的关系 |

@@point ② NLP 研究的四个层级：词法、句法、语义、语用
@@need 要解决什么
"理解语言"这句话太抽象，NLP 是怎么层层递进组织任务的？

@@idea 核心思路
语言处理是分层的，从"字面"到"含义"逐级深入：

| 层级 | 处理对象 | 典型问题 |
|---|---|---|
| 词法层 | 词 | 分词、词性标注、命名实体识别 |
| 句法层 | 句子结构 | 依存分析、句法树、短语划分 |
| 语义层 | 含义 | 词义消歧、语义角色标注、情感分析 |
| 语用层 | 语境与意图 | 对话意图识别、指代消解、言外之意 |

后面章节先做词法层（jieba 分词、词性标注），再逐步爬到语义层（词向量、注意力），最后到预训练模型（BERT、GPT）这种"一层全包"的形态。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 跳过词法直接学大模型 | 预训练模型内部也包含分词（tokenize）环节，不懂词法就看不懂输入输出的形状 |
| 把"分对词"当最终目标 | 分词只是手段，最终目标是让下游任务（分类、翻译、问答）更准 |

@@point ③ NLP 的经典任务全家桶
@@need 要解决什么
学了 NLP 之后具体能落地哪些活儿？任务之间有什么区别？

@@idea 核心思路
按"输入输出形态"可以把 NLP 任务归成几大类：

- **文本分类**：输入一句话，输出类别（情感正负、新闻主题、垃圾邮件）。
- **序列标注**：输入一个序列，给每个词打标签（词性、人名地名机构名、实体边界）。
- **文本匹配**：输入两个句子，判断关系（语义等价、蕴含、问答对）。
- **文本生成**：输入提示，输出新文本（翻译、摘要、续写、对话）。
- **信息抽取**：从非结构化文本中抽出结构化事实（实体、关系、事件）。

本阶段覆盖的正是这条线：分词与词性（序列标注）、关键词（抽取）、翻译与生成（Seq2Seq/Transformer/GPT）、理解（BERT）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 分不清"分类"和"生成"的差别 | 分类输出是固定标签集合里的一个；生成输出是长度不定的新token序列，建模方式完全不同 |
| 以为一个模型通吃所有任务 | 理解类任务（BERT 系）和生成类任务（GPT 系）各自擅长不同领域，选型要看任务本质 |

@@point ④ NLP 的发展历程：三大代际
@@need 要解决什么
NLP 是怎么一步步从"查词典"进化到"ChatGPT"的？

@@idea 核心思路
NLP 的发展大致走过三个阶段：

1. **规则时代**：人工编写语法规则和词典，靠"if-else"匹配。可解释但覆盖面窄，遇到口语、长句就崩。
2. **统计学习时代**：从大规模语料里统计词频、共现（TF-IDF、N-gram、HMM）。泛化性大幅提升，但特征仍靠人工设计。
3. **深度学习与预训练时代**：Word2Vec 把词变成稠密向量 → RNN/LSTM 建模序列 → 注意力机制与 Transformer → 2018 年起 BERT（理解）与 GPT（生成）开启"预训练+微调/提示"范式，也就是今天大模型的原型。

本阶段 17 章正好完整复现这条演进线：词向量 → RNN → Transformer → ELMo/BERT/GPT。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为大模型凭空出现 | 今天 Transformer 的每个部件（注意力、位置编码、掩码）都能在旧模型里找到思想源头，按演进顺序学才学得动 |
| 只看结论不追演进动机 | 每个新模型都是为了解决前一个的缺点而生，带着"它解决了什么"学，效率翻倍 |

@@point ⑤ 机器怎么"看见"文本：文本表示问题
@@need 要解决什么
神经网络只能吃数字，一段中文句子怎么变成它吃得下的东西？

@@idea 核心思路
文本要进入模型，必须经过**文本表示（Text Representation）**，把语言符号映射成数值：

```
"我爱学习" → [分词] → ["我", "爱", "学习"] → [查表] → [[0.12, -0.3, ...], ...]
```

表示方式的层次：

- **离散表示**：one-hot 编码——每个词一个 0/1 向量，简单但稀疏、无语义、维数灾难（后面词向量章详讲）。
- **分布式表示**：词嵌入（Word2Vec/ELMo/BERT）——用稠密低维向量表达语义，语义相近的词向量相近。
- **上下文表示**：同一个词在不同句子里得到不同向量（ELMo/BERT 的动态词向量），解决一词多义。

这一章的"文本表示"是概念铺垫，第 5 章（Word2Vec）、第 15-17 章（ELMo/BERT/GPT）会逐级落地。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为分词后直接喂给模型就行 | 模型吃的是 token 的离散 ID 或向量，中间必须过词汇表映射，词汇表怎么建决定覆盖面 |
| 混淆"词向量"和"token ID" | token ID 是查表下标，词向量是查表结果；前者是索引，后者才是模型计算的对象 |

@@point ⑥ 中文 vs 英文：处理难在哪
@@need 要解决什么
为什么讲 NLP 总把中文单拎出来说？中文文本的难点是什么？

@@idea 核心思路
中英文的"最小处理单元"完全不同：

- **英文**：词天然用空格分隔，`I love NLP` 直接 split 就得到词；剩下的是时态、单复数变形问题。
- **中文**：字与字之间没有空格，一句话是连续的字符流，**必须先分词**才知道语义边界。

中文难点集中在这几点：

1. **分词歧义**："武汉市长江大桥"该切成"武汉/市长江大桥"还是"武汉市/长江大桥"？两种切法都对，但语义不同。
2. **未登录词**：人名、地名、网络新词不在词典里（"给力""躺平"）。
3. **一词多义**："苹果"可能是水果也可能是手机品牌，必须靠上下文。
4. **字构词、词成句**：层级嵌套（"大/学"、"大学/生"），边界不清晰。

这一系列问题催生了 jieba 这样的专门中文分词工具（下一章）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 把中文分词工具的思路照搬到英文 | 英文空格分词基本够用，硬套中文式词典反而引入错误 |
| 以为分词错误无伤大雅 | 分词是第一步，错一个词边界，后面词性、关键词、语义全链路由错 |

@@point ⑦ 为什么不先上大模型，还要学分词、词向量
@@need 要解决什么
既然 BERT/GPT 那么强，直接从大模型学起不行吗？

@@idea 核心思路
大模型不是黑箱，它内部每一步都能对应到经典概念：

- 大模型的**分词器（Tokenizer）**本质就是"子词分词"——比 jieba 更细，但思路同源（BPE/WordPiece 也是从词频统计出发）。
- 大模型的**输入嵌入**就是词向量的进阶版（加入位置编码、段落嵌入）。
- 大模型的**自注意力**就是本章后面要学的注意力机制放大了 N 层。
- 大模型的**预训练-微调**范式，思想原型就是 Word2Vec 的"预训练词向量 + 下游任务复用"。

先学经典再学大模型，等于拿着一份"零件说明书"去看整机——能看懂、能调参、能排查问题；直接从大模型入门，遇到问题只能瞎猜。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 跳过基础直接跑大模型 demo | demo 能跑但不会改，一旦要换数据、换任务就无从下手 |
| 轻视"老模型" | 老模型是概念的最小化实现，训练快、可剖析，是理解新模型的阶梯 |

@@point ⑧ 本阶段的学习路线
@@need 要解决什么
第 1 章到第 17 章，怎么安排才能把 NLP + Transformer 这条线学通？

@@idea 核心思路
本阶段的推进路线非常清晰，按"表示 → 序列建模 → 注意力 → 预训练大模型"四步走：

1. **文本表示**（第 1-5 章）：NLP 认知 → jieba 分词 → 关键词/词性 → NLTK → Word2Vec 词向量。
2. **序列建模**（第 6-9 章）：RNN 原理 → 歌词生成实战 → LSTM → GRU 与双向 RNN。
3. **注意力与 Transformer**（第 10-14 章）：Seq2Seq → 注意力机制 → 自注意力 → 多头注意力与位置编码 → 整体架构与翻译实战。
4. **预训练大模型**（第 15-17 章）：ELMo → BERT → GPT。

每一章都在为下一章"架梯子"：Word2Vec 的局限引出 ELMo，RNN 的顺序处理引出注意力，Transformer 编码器引出 BERT、解码器引出 GPT。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 跳着看，只学 Transformer 相关章节 | 前面词向量、RNN 的"痛点"正是 Transformer 的诞生动机，跳过会丢失"为什么" |
| 教程看完不敲代码 | 每章都有小实战（分词、歌词生成、翻译），代码亲手跑一遍才算真会 |

@@summary
本章建立了 NLP 的整体认知：

| 问题 | 答案 |
|---|---|
| NLP 是什么 | 让机器理解、处理、生成人类语言的学科 |
| 研究层级 | 词法 → 句法 → 语义 → 语用 |
| 经典任务 | 分类、序列标注、匹配、生成、抽取 |
| 发展历程 | 规则 → 统计 → 深度学习 → 预训练大模型 |
| 文本表示 | 离散(one-hot) → 分布式(词向量) → 上下文(动态) |
| 中文难点 | 无空格需分词、歧义、未登录词、一词多义 |
| 学习路线 | 分词/词向量 → RNN → Transformer → ELMo/BERT/GPT |

一句话记住本章：**NLP 是给计算机搭"语言数字桥"，文本先分词再做向量表示，然后交给序列模型或注意力模型去理解，本阶段 17 章就沿着"表示→建模→预训练"这条线逐步深入。**
