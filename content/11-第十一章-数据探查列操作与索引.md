@@point ① 探查四件套：head / info / shape / describe
@@need 要解决什么
拿到一张陌生表，**第一件事看什么？** 四个方法把"长相、规模、类型、分布"全给你。

@@idea 核心思路

```python
import pandas as pd

df = pd.read_csv('data.csv')

df.head()          # 前 5 行（默认）快速看结构；df.tail() 看尾部
df.info()          # 行数、列数、各列非空计数与 dtype——最重要！
df.shape           # (行数, 列数) 元组
df.describe()      # 数值列统计：count/mean/std/min/25%/50%/75%/max
```

使用节奏：

- **info() 一眼看全貌**：每列多少非空、什么类型——先查空值与类型，最该第一步做；
- **describe() 看数值分布**：范围、均值、四分位，发现"离群嫌疑";
- **shape 记规模**：后续任何操作前确认行数列数和你预期一致。

debug 习惯：**任何操作前后都 head() 对比**——这是所有老手排查 Pandas 问题的开场动作。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| describe() 只有 8 行、没显示所有列 | 它默认只统计数值列；字符串列要用 df.describe(include='object') |
| info() 列很多显示被截断 | df.info(verbose=True) 显示全部列详情 |

@@point ② rename：改列名 / 改索引名
@@need 要解决什么
**读进来的列名叫"Unnamed: 0"、英文不好读，想批量改名。** rename 一处改多个，支持列和索引。

@@idea 核心思路

```python
df = pd.DataFrame({'姓名': ['张', '王'], '数学': [88, 95]})

df.rename(columns={'数学': 'math'})        # 列改名（返回新表）
df.rename(columns={'数学': 'math'}, inplace=True)   # 原地改
df.rename(index={0: '第一行'})             # 索引标签改名
```

记忆：

- **columns= 改列名，index= 改索引名**；
- 默认返回新表，`inplace=True` 才原地改；
- rename 只改"你点名的"，其他原封不动——适合局部微调。

批量规范想法：列名系统化（小写下划线风格）用 `df.columns = [新名列表]` 或 `df.columns.str.lower()`。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| rename 后原表没变 | 默认返回新对象，忘了赋值或 inplace=True |
| 改名字典写反（把旧名当值） | 映射方向是 {旧名: 新名}，别反 |

@@point ③ drop：删列与删行
@@need 要解决什么
**不需要的列/行怎么删？** drop 按标签删，轴参数决定删列还是删行。

@@idea 核心思路

```python
df = pd.DataFrame({'A': [1, 2], 'B': [3, 4], 'C': [5, 6]})

df.drop(columns='B')               # 删列 B
df.drop(columns=['A', 'C'])        # 批量删列
df.drop(index=0)                   # 删行（按索引标签）
df.drop(['A'], axis=1)             # 老写法：axis=1 表示列
```

要点：

- **删行按索引标签**（index=0 删的是"标签为 0 的行"，不是"第 0 行"——数值标签时容易误会）；
- **删不存在的标签默认报 KeyError**，可加 errors='ignore' 容错；
- 同理默认返回新表。

删除与选择：**"不要哪几列"用 drop，"只要哪几列"用 df[列列表]**——两个思维方向都要会。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| drop(0) 删的不是我以为的那行 | drop 按标签定位，不是位置；按位置删除需要 iloc（第 12 章） |
| axis 记不清 | 用 columns=/index= 关键字就永远不混淆（axis=1 是列） |

@@point ④ 获取列与新增列
@@need 要解决什么
取一列、取多列、**在表里加一列（计算列/常量列）**——列的"增取"二件套。

@@idea 核心思路

```python
df = pd.DataFrame({'数学': [88, 95], '语文': [76, 90]})

df['数学']                      # 取一列 → Series
df[['数学', '语文']]            # 取多列 → DataFrame（注意双层括号）

df['总分'] = df['数学'] + df['语文']   # 新增"总分"列（计算式）
df['标记'] = 'OK'                     # 新增常量列（广播）
df.loc[:, '新列'] = [1, 2]            # 另一种新增方式
```

要点：

- **df['不存在列'] = 值** → 自动新增列并填值（值可为 Series/列表/标量）；
- **已存在的列赋值 → 覆盖整列**（长度必须对齐，否则报错）；
- 列顺序：新列默认加在**最右**；要插到中间用 insert（第 ⑥ 点）。

计算列是数据清洗最常见动作：`df['平均分'] = (df['数学'] + df['语文']) / 2`。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 给新列赋列表长度和行数不齐 | 长度必须一致；不一致报错（RuntimeWarning/aligment） |
| 新列在最右边不想要 | insert 指定位置（第 ⑥ 点） |
| 想两个条件生成列 | 用 np.where 或 apply 函数（第 ⑤ 点） |

@@point ⑤ apply / map：函数应用到数据
@@need 要解决什么
**对每行/每列做自定义计算**（如成绩≥60 转"及格"/"不及格"）——apply 管行或列，map 管 Series 逐元素。

@@idea 核心思路

```python
import pandas as pd

df = pd.DataFrame({'成绩': [88, 55, 73]})

# map：对 Series 逐元素应用（返回新 Series 再赋给列）
df['是否及格'] = df['成绩'].map(lambda x: '及格' if x >= 60 else '不及格')

# apply：对 DataFrame 按行/列应用（axis=0 列、axis=1 行）
df['成绩翻倍'] = df['成绩'].apply(lambda x: x * 2)

# 元组展开应用（多列进函数）
df['备注'] = df.apply(lambda r: f"{r['成绩']}分", axis=1)
```

适用边界：

- **Series.map**：一列的逐元素映射（含字典映射：`.map({'及格': 1, '不及格': 0})`）；
- **DataFrame.apply(axis=1)**：一行多列组合进函数（业务规则最常用）；
- 性能提示：apply 逐行 Python 循环，**大表慢**；能用向量化（+ - * /）就不用 apply。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| apply(axis=1) 遍历的是行还是列 | axis=1 遍历行，函数接收一行 Series |
| 大表 apply 卡死 | 先看能否改向量化表达式（df['a']+df['b']）；apply 是最后手段 |
| map 用于 DataFrame 报错 | map 是 Series 方法；DataFrame 用 apply 或 applymap |

@@point ⑥ insert / assign：插入新列
@@need 要解决什么
新列默认加最右，**想在指定位置插列**用 insert；**想"链式"一口气加多列**用 assign。

@@idea 核心思路

```python
df = pd.DataFrame({'数学': [88, 95], '语文': [76, 90]})

# insert：指定位置插入
df.insert(1, '英语', [80, 82])          # 第 1 列位置（0 起）插"英语"
df['总分'] = df.sum(axis=1)

# assign：一次加多列（返回新表，不原地改！）
df2 = df.assign(平均=df['总分'] / 3,
               评价=lambda d: d['总分'].apply(lambda x: '优' if x > 250 else '良'))
```

区别：

- **insert 原地改**（inplace 设计），必须在具体位置；
- **assign 返回新表、不原地改**，支持用 lambda 引用刚建的表（链式编程）；
- 想"边加边算"且要新列参与后续列的公式 → assign 的 lambda 特性。

二选一规则：**个人脚本简单插入用 insert；复杂链路/一步多列用 assign（链式）**。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| assign 后原表没新列 | assign 返回新表，需 df = df.assign(...) 接收 |
| insert 位置越界 | 位置从 0 到列数；插入最左是 0，最右是 len(df.columns) |

@@point ⑦ astype / to_numeric：类型转换
@@need 要解决什么
**"年龄"列读进来是字符串、算不了平均**；或者小数点太多——类型转换三件套。

@@idea 核心思路

```python
import pandas as pd

df = pd.DataFrame({'年龄': ['20', '35', '28'], '工资': ['5k', '8k', '7k']})

# astype：直接转换（要能转得动）
df['年龄'] = df['年龄'].astype(int)

# to_numeric：更稳，出错处变 NaN 而不是抛异常
df['工资数字'] = pd.to_numeric(df['工资'].str.replace('k', ''), errors='coerce')

# errors='coerce'：转不动的变 NaN，程序不中断
```

规则：

- **astype(int/float/str/bool)**：最快，但转不动直接抛 ValueError；
- **pd.to_numeric(series, errors='coerce')**：容错转换，坏值变 NaN（推荐用于真实脏数据）；
- 转换后仍是"同一列"，要么覆盖赋值：`df['年龄'] = df['年龄'].astype(int)`。

先 info() 看 dtype，再决定转哪列——**类型问题是 Pandas 排名第一的隐性 bug**。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| astype(int) 遇到 '五' 类转不动报错 | 用 to_numeric(errors='coerce') 容错，或先清洗数据 |
| 转换成功但计算还是不对 | 转完忘了覆盖赋值：df['列'] = df['列'].astype(int) |
| 串值有空格转不动 | strip 去空格后再转 |

@@point ⑧ set_index / reset_index：行索引管理
@@need 要解决什么
**想把"姓名"列设成行标签**（像 Excel 的表头行）/反过来把索引"物化"成普通列——set/reset 一对反操作。

@@idea 核心思路

```python
df = pd.DataFrame({'姓名': ['张', '王'], '成绩': [88, 95]})

df2 = df.set_index('姓名')            # 姓名列 → 行索引
#       成绩
# 姓名
# 张     88
# 王     95

df3 = df2.reset_index()               # 索引 → 普通列（变回原来样子）
#   姓名  成绩
# 0  张   88
```

注意事项：

- **set_index 会"消耗"掉这一列**（它变成索引了），想保留副本先 df.copy()；
- **reset_index 把索引列恢复成普通列**，默认加一列名叫原索引名；
- 默认都返回新表。

实际场景：按日期做时间索引（第 13 章时间序列必备）、分组统计后索引变组合键（第 12 章 groupby 后会频繁遇到 reset_index）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| set_index 后原列不见了 | 正常，它变成索引了；要保留先复制再操作 |
| groupby 后想把它当普通表 | reset_index() 释放索引成列——groupby 的标配善后操作 |
| set_index 没生效 | set_index 返回新表，需赋值接收 |

@@point ⑨ 索引排序与重排
@@need 要解决什么
**索引乱了想按标签顺序排、想倒序**——sort_index 管"索引排序"，它和 sort_values（按值排）是两回事。

@@idea 核心思路

```python
import pandas as pd

df = pd.DataFrame({'成绩': [88, 95, 76]}, index=['b', 'c', 'a'])

df.sort_index()                # 按索引标签排序：a b c
df.sort_index(ascending=False) # 降序：c b a
df.sort_values('成绩')          # 按成绩值排序（对比用）
df.sort_values('成绩', ascending=False)   # 成绩降序
```

分清：

- **sort_index：按行索引/列名**排（axis=0 行、axis=1 列）；
- **sort_values：按数据值**排（传列名）。

排序后是否重置索引：排序只是重排位置，索引跟着行走（不重置）；要"序号 0,1,2…"再 reset_index(drop=True)。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| sort_index 和 sort_values 老混 | 一句话：index 按标签、values 按数值 |
| 排序后还想序号连续 | df = df.sort_values('成绩').reset_index(drop=True) |

@@point ⑩ reindex：按新索引顺序重排
@@need 要解决什么
**想按自己定义的顺序重排行**（如"周一、周三、周二"），或**补全缺失的索引**（缺的补 NaN）——reindex。

@@idea 核心思路

```python
import pandas as pd

s = pd.Series([88, 95, 76], index=['数学', '英语', '语文'])

s.reindex(['语文', '数学', '英语'])      # 按指定顺序重排
s.reindex(['语文', '数学', '物理'])      # 缺'物理' → NaN（自动补缺失）
s.reindex(...， fill_value=0)            # 缺失值填默认值
```

特性：

- **reindex 按"给定顺序"重排**，不在指定清单里的行会被丢弃；
- 指定了但源里没有的标签 → 自动产生 NaN 行（**一次性把"缺失对齐"也干了**）；
- 常用于日期补齐（时间索引缺日补空）、统一两表行序对齐。

与 sort_index 区别：**sort 是自动排序，reindex 是按你给定的顺序**。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| reindex 把多余行丢了 | 设计如此：只保留你指定的标签集合 |
| 补出来的 NaN 后面统计通通 NaN | 先 fillna（第 12 章缺失值）再继续算 |

@@summary
这一章，Pandas 的"看与改"基本功齐活：

| 能力 | 函数 | 一句话 |
|---|---|---|
| 探查 | head/info/shape/describe | 先看长相规模类型分布 |
| 改列名 | rename(columns=) | 局部改名，inplace 可原地 |
| 删列行 | drop(columns=/index=) | 按标签删 |
| 增取列 | df['新']=值 / df[['a','b']] | 计算列自动加最右 |
| 函数应用 | map（Series）/ apply（行/列） | 逐元素/逐行自定义逻辑 |
| 插列 | insert / assign | 定位置插 / 链式多列 |
| 类型转换 | astype / to_numeric(coerce) | 前者快后者稳 |
| 索引管理 | set_index / reset_index | 列变索引 / 索引变列 |
| 排序 | sort_index / sort_values | 标签排 / 数值排 |
| 重排 | reindex | 按你给的顺序排，缺失补 NaN |

一句话记住本章：**先 head/info/describe 摸家底，再用 rename/drop/新增列改结构，apply/map 上业务逻辑，astype 定型、set/reset/reindex 管索引——改表的每一步都记得"返回新表要赋值"。**
