@@why 这一章在解决什么问题
上一章的线性模型只能拟合直线关系，而真实世界大多是非线性的。神经网络把多个"神经元"堆叠起来，配上**激活函数**引入非线性，才能拟合复杂规律。这一章讲清楚神经网络的基本组成、前向传播的计算流程，以及 ReLU、Sigmoid、Tanh 等常用激活函数各自解决什么问题、什么时候用哪个。

@@point ① 从单个神经元到多层网络
@@need 要解决什么
一个神经元凭什么能学习？多个神经元叠起来又强在哪？

@@idea 核心思路
单个神经元的计算分两步：

```python
z = w1*x1 + w2*x2 + b   # 线性加权求和
a = activation(z)       # 激活函数引入非线性
```

多个神经元**按层堆叠**就构成多层网络：

- **输入层**：接收原始特征。
- **隐藏层**：一层或多层，每层有若干神经元，是"特征再加工"的地方。
- **输出层**：给出最终预测（回归输出一个数，分类输出各类概率）。

每层神经元的输出，是下一层所有神经元的输入——**层层嵌套的复合函数**。复合函数有强大的表达能力，再配合激活函数的非线性，理论上可以逼近任意连续函数。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 层数越多越好吗 | 层数增加能拟合更复杂关系，但需要更多数据、更久训练，还容易过拟合；先浅后深 |
| 隐藏层神经元个数怎么定 | 无定式：先参考同类任务规模，过拟合就减小、欠拟合就增大 |
| 以为线性堆叠就等于非线性 | **没有激活函数的层叠再多也等价于一层的线性变换**（矩阵乘法可合并），必须靠激活函数 |

@@point ② 前向传播：数据是怎么流过网络的
@@need 要解决什么
一个样本从输入到输出，中间到底发生了哪些计算？

@@idea 核心思路
**前向传播（forward）** 指数据从输入层一路算到输出层的完整过程：

```python
# 手写版：直观展示前向传播的本质
def forward_manual(x, W1, b1, W2, b2):
    h = torch.relu(x @ W1 + b1)   # 输入→隐藏层 + 激活
    y = h @ W2 + b2               # 隐藏层→输出层
    return y
```

关键理解：

- 每一层 = `线性变换（权重矩阵乘输入 + 偏置）` → `激活函数`。
- 隐藏层的输出 `h` 是下一层的"输入"，逐层传递。
- 所有权重 W、偏置 b 都是**可学习参数**，由反向传播更新。

前向传播决定"预测是什么"，反向传播决定"参数怎么改"，两者配合完成学习。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 维度对不上报错 | 相邻两层必须匹配：W1 形状是 [输入维度, 隐藏维度]，W2 是 [隐藏维度, 输出维度] |
| 忘了加偏置 b | 模型表达能力下降；b 是每层的"偏移量"，让分界不必须过原点 |
| 把 @ 写成 * | 层间传递是**矩阵乘法** @，不是逐元素乘 * |

@@point ③ Sigmoid：压缩一切的"老牌"激活
@@need 要解决什么
怎么把任意数值压缩到 (0,1) 之间，当概率用？

@@idea 核心思路
**Sigmoid** = 1 / (1 + e^(-z))，把任意实数压到 **(0, 1)**：

```python
x = torch.tensor([-5.0, 0.0, 5.0])
print(torch.sigmoid(x))  # tensor([0.0067, 0.5000, 0.9933])
```

适用场景：
- 二分类输出层（输出可解释为"属于正类的概率"）。
- 需要 0~1 归一化的门控机制（如 LSTM 的门）。

**核心缺点**：
- 输出不以 0 为中心，减缓收敛。
- 两头"饱和"：z 很大或很小时梯度趋近 0——**梯度消失**的元凶之一，深层网络几乎不再用它做隐藏层。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 深层网络隐藏层用 Sigmoid | 梯度消失严重；隐藏层优先 ReLU 系 |
| 输出不能是概率仍用 Sigmoid | 三分类以上输出层用 **Softmax**，把全体输出归一化成概率分布 |
| 饱和区梯度接近 0 | 训练几乎停摆；警惕长时间 loss 不下降 |

@@point ④ Tanh：Sigmoid 的升级版
@@need 要解决什么
想要输出以 0 为中心、还在 (-1,1) 范围，怎么办？

@@idea 核心思路
**Tanh** = (e^z - e^(-z)) / (e^z + e^(-z))，把实数压到 **(-1, 1)**，且**以 0 为中心**：

```python
x = torch.tensor([-1.0, 0.0, 1.0])
print(torch.tanh(x))   # tensor([-0.7616, 0.0000, 0.7616])
```

相对 Sigmoid 的优势：**均值接近 0**，优化速度更快（后续讲 Adam 公式时，EWMA 归一化的思想与之呼应）。

**缺点依旧**：两端同样饱和，深层网络仍有梯度消失风险。现代深层网络隐藏层更常用 ReLU。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 输出范围记混 | Tanh 是 (-1,1)；Sigmoid 是 (0,1)，后者多用于概率输出 |
| 以为 Tanh 解决了一切 | 饱和问题仍在；回归输出层一般不直接用 Tanh（除非目标值本身在 (-1,1)） |

@@point ⑤ ReLU：现代网络的默认选择
@@need 要解决什么
既想要非线性，又想要梯度不消失，怎么办？

@@idea 核心思路
**ReLU** = max(0, z)：

```python
x = torch.tensor([-2.0, 0.0, 3.0])
print(torch.relu(x))   # tensor([0., 0., 3.])
```

优点：
- 正区间梯度恒为 1，**有效缓解梯度消失**，深层网络训练更稳。
- 计算极快（一次比较）。
- 天然产生**稀疏激活**（负值全部归 0），类似人脑"部分神经元不响应"。

代价：
- 负区间梯度为 0，如果某神经元输入长期为负，它会"死掉"（**神经元死亡**），输出恒为 0 不再更新。

现代 CNN/MLP 的隐藏层默认 ReLU，几乎家家都在用。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 神经元输出长期恒 0 | 可能"死掉"：学习率过大或初始化不当；换 LeakyReLU 或降学习率 |
| 输出层用 ReLU | 回归目标全为非负时才勉强能用；**含负值必须用线性输出**，分类概率输出必须 Softmax/Sigmoid |
| 负输入梯度为 0 担心 | 稀疏是特性不是 bug；多数场景收益大于损失 |

@@point ⑥ Softmax：把输出变成概率分布
@@need 要解决什么
多分类时，怎么让网络的多个输出"凑成加起来等于 1 的概率"？

@@idea 核心思路
**Softmax** 把 K 个输出变成 K 个非负且和为 1 的概率：

```python
logits = torch.tensor([2.0, 1.0, 0.1])
probs = torch.softmax(logits, dim=0)
print(probs, probs.sum())  # 和为 1，最大概率对应最大 logit
```

关键点：
- 漏斗特点：**大的更大、小的更小**（指数放大差距），很像"竞争"选出最可能的类。
- 与交叉熵损失天然搭配：`CrossEntropyLoss` 在 PyTorch 里**内部已包含 Softmax**，用它时不要手动再过一遍 Softmax。
- 用于多分类（≥3 类）输出层；二分类用 Sigmoid 即可。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| CrossEntropyLoss 前又手动 Softmax 一遍 | 双重 softmax，结果错但不易察觉；PyTorch 的 CE 已内置 |
| 只看概率不看 logits | 一些技巧（温度缩放、蒸馏）操作在 logits 上更直接 |
| dim 参数写错 | 分类张量 `(N, C)` 要沿**类别维 `dim=1`**；`dim=0` 是对 batch 维逐列归一化，几乎总是错的 |

@@point ⑦ 激活函数对比总表
@@need 要解决什么
讲了这么多，实战中到底怎么选？

@@idea 核心思路
一张表收尾对比：

| 激活 | 公式 | 输出范围 | 主要用途 | 主要问题 |
|---|---|---|---|---|
| Sigmoid | 1/(1+e^-z) | (0,1) | 二分类输出层 | 饱和区梯度消失 |
| Tanh | (e^z-e^-z)/(e^z+e^-z) | (-1,1) | 0 中心场景 | 仍会饱和 |
| ReLU | max(0,z) | [0,+∞) | **隐藏层默认** | 负区间神经元死亡 |
| LeakyReLU | z 若 z>0 否则 αz | R | 缓解 ReLU 死亡 | 需调 α（默认 0.01） |
| Softmax | e^z_i/Σe^z_j | (0,1) 和=1 | 多分类输出层 | 与 CE 别重复用 |

**实战口诀**：隐藏层默认 ReLU（死亡严重换 LeakyReLU）；二分类输出层用 Sigmoid，多分类用 Softmax；不用手写，PyTorch 全有。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 记不住谁是谁 | 按输出范围记：Sigmoid(0,1)、Tanh(-1,1)、ReLU(0,∞)、Softmax 和为 1 |
| 一个网络所有层用同一种 | 输入/隐藏层与输出层可以不同（如隐藏 ReLU + 输出 Sigmoid） |
| 亲手实现 Softmax 数值不稳定 | 大 logit 导致 e^z 爆炸；框架已做数值稳定处理，别手搓 |

@@point ⑧ ReLU 家族：LeakyReLU、ELU、GELU
@@need 要解决什么
ReLU 有"神经元死亡"的毛病，有没有它的改良亲戚？

@@idea 核心思路
围绕 ReLU 的缺陷，学界给出了一系列改良：

| 激活 | 负区间行为 | 特点 |
|---|---|---|
| **LeakyReLU** | αz（默认 α=0.01） | 负区间有小梯度，不死神经元 |
| **ELU** | α(e^z − 1) | 负区间平滑趋近 -α，更稳但稍贵 |
| **GELU** | z·Φ(z) | Transformer 标配（BERT/GPT 内部用它），平滑且自适应 |

```python
import torch.nn as nn
l = nn.LeakyReLU(negative_slope=0.01)   # 常用
e = nn.ELU(alpha=1.0)
g = nn.GELU()
```

**选型建议**：
- 常规 MLP/CNN：ReLU 仍是默认，性价比最高。
- 发现大量神经元"死掉"（训练一段时间看激活分布）：换 **LeakyReLU**。
- 做 Transformer 类模型：直接用 **GELU**。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 死神经元怎么发现 | 打印各层输出的平均激活，接近 0 且几乎不动就是死了 |
| 以为新激活一定更好 | GELU 有计算开销且非所有任务都增益；先 ReLU 基线，有问题再换 |
| LeakyReLU 的 slope 乱调成很大 | 负斜率过大正负无差别，近似线性；默认 0.01 起步 |

一句话记住本章：**神经网络就是"线性+非线性"逐层堆叠的复合函数；激活函数是引入非线性的唯一来源——隐藏层默认 ReLU，二分类输出 Sigmoid，多分类输出 Softmax（CE 内置，别再叠一次）。**


@@summary
神经网络与激活函数的关键结论：

| 问题 | 答案 |
|---|---|
| 网络结构 | 输入层 + 一个或多个隐藏层 + 输出层，层层复合 |
| 前向传播 | 逐层"矩阵乘 + 偏置 + 激活"，数据从输入流到输出 |
| 为什么需要激活 | 没有它，多层线性变换等价单层，学不了非线性 |
| Sigmoid | (0,1)，二分类输出层；隐藏层梯度消失 |
| Tanh | (-1,1)，0 中心；仍会饱和 |
| ReLU | max(0,z)，现代隐藏层默认，缓解梯度消失 |
| Softmax | 和为 1 的概率分布，多分类输出；CE 已内置勿重复用 |
