@@point ① 裸 SGD 的两个痛点
@@need 要解决什么
裸 SGD 在什么地形上会"翻车"？

@@idea 核心思路
裸 SGD 的更新规则就是 `param -= lr * grad`，它只认"当前一步的坡度"，没有任何历史记忆。两个典型痛点：

1. **峡谷震荡**：损失面像一个峡谷（比如损失在参数 a 方向很陡、在 b 方向很缓），SGD 会在陡的方向来回弹跳，缓的方向却走不动——明明方向对，却走得歪歪扭扭。
2. **平坦高原**：梯度接近于 0 的地方，SGD 几乎不动，像陷在泥里。

对策思路很自然：**给下山加上"惯性"（动量），给每个参数配上"自己的步长"（自适应学习率）**——后面所有算法都在做这两件事。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| loss 曲线在震荡 | 典型峡谷问题；上动量（SGD+Momentum）或换 Adam |
| 平坦期 loss 停滞很久 | 梯度太小；自适应学习率（RMSProp/Adam）更擅长突破 |
| 以为优化器只是"SGD 的替代品" | 优化器是完整的参数更新策略：动量、二阶矩、自适应都在里面 |

@@point ② Momentum：给下山加惯性
@@need 要解决什么
如何在峡谷里减少来回震荡、同时加快前进速度？

@@idea 核心思路
**Momentum（动量）** 引入"速度"概念：每次更新不只由当前梯度决定，还**叠加之前的运动方向**：

```
v = momentum * v_prev - lr * grad      # 惯性 + 当前推力
param = param + v
```

想象滚雪球下山：在震荡的峡谷里，上下方向的"来回"被平均抵消，而前行方向持续累积——**震荡被抑制、前进被加速**。

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
```

momentum 常取 0.9（保留 90% 的历史速度）。动量越大，惯性越强，越不容易被局部地形带偏，但也越"迟钝"，注意别过冲。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 动量太大会怎样 | 惯性过猛，冲过最优点附近来回越划越大；momentum 从 0.9 降到 0.5 试试 |
| 动量为 0 与裸 SGD 等价 | 是的；momentum=0 就是普通 SGD |
| 换 Adam 后疑惑"动量参数去哪了" | Adam 有自己的动量（一阶矩）与二阶矩，接口参数叫 betas=(0.9, 0.999) |

@@point ③ EWMA 与 Adagrad：给每个参数定制步长
@@need 要解决什么
不同参数的量级、出现频率差异大，能不能让它们"各自配速"？

@@idea 核心思路
先补一个小工具概念：**EWMA（指数加权移动平均）**——给过去的数值指数衰减地加权，越近影响越大，是用来"平滑一段历史"的通用手法（Momentum、RMSProp 等内部都在用它）。

**Adagrad** 是自适应学习率的开山之作：**每个参数用自己的历史梯度平方和来缩放学习率**——更新大的参数降速，更新小的参数加速：

```
param -= lr / sqrt(G + eps) * grad   # G 是梯度平方的累积
```

```python
optimizer = torch.optim.Adagrad(model.parameters(), lr=0.01)
```

优点：**无需操心不同尺度的特征**，稀疏数据（如词向量，多数维度更新频率低）效果好。

**致命缺点**：G 只增不减，累到后期分母过大 → 学习率趋近 0，**训练提前停摆**。这催生了 RMSProp。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| Adagrad 训练后期 loss 不再下降 | 学习率被越拖越小，趋于 0；这是 Adagrad 固有毛病，换 RMSProp/Adam |
| 把 G 做成"历史总和"而非均值 | Adagrad 就是总和（不带遗忘）；RMSProp 才用滑动平均 |
| 只想要自适应不想要累积缺点 | 直接上 RMSProp 或 Adam，别在 Adagrad 上死磕 |

@@point ④ RMSProp：滑动平均版的自适应
@@need 要解决什么
既要自适应的好处，又要避免学习率越滚越小，怎么办？

@@idea 核心思路
**RMSProp** 用 **EWMA 滑动平均**替换 Adagrad 的"平方和累积"：

```
v = beta * v_prev + (1 - beta) * grad^2      # 平滑的历史平方梯度
param -= lr / sqrt(v + eps) * grad
```

关键差异：**滑动平均有"遗忘"**，近期的梯度才主导分母 → 学习率不会无限缩小，在 Adagrad 后期停摆的平原区仍能继续走。

```python
optimizer = torch.optim.RMSprop(model.parameters(), lr=0.01, alpha=0.99)
```

**本质**：RMSProp = Adagrad 的思路 + EWMA 的遗忘机制。它也是 Adam 的核心构件之一。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| alpha 与 beta 分不清 | alpha（RMSProp 的平滑系数）≈ Adam 的 beta2；都是对二阶矩的衰减 |
| RMSProp 更新方向仍只有"梯度项" | 它没有动量，方向仍由当前梯度主导；想要惯性再上 Adam |
| loss 炸了先怀疑优化器 | 先查学习率，再查数据归一化，最后才是优化器超参 |

@@point ⑤ Adam：今天的事实标准
@@need 要解决什么
能不能把动量 & 自适应学习率**两者都**要？

@@idea 核心思路
**Adam（Adaptive Moment Estimation）** = **动量（一阶矩 m）+ RMSProp（二阶矩 v）** 合体：

```
m = beta1 * m_prev + (1 - beta1) * grad      # 一阶矩：动量
v = beta2 * v_prev + (1 - beta2) * grad^2    # 二阶矩：自适应分母
m_hat = m / (1 - beta1^t)                    # 偏差校正（初期修正）
v_hat = v / (1 - beta2^t)
param -= lr * m_hat / (sqrt(v_hat) + eps)
```

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

默认超参（几乎不用动）：
- lr = 0.001
- betas = (0.9, 0.999)（动量系数 0.9、二阶矩系数 0.999）
- eps = 1e-8（防除零）

**为什么是标准**：既有动量冲震荡、又有自适应步长适应平原，还做了偏差校正（前几步更稳），对超参不敏感，几乎开箱可用。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| Adam 默认 lr=0.001 却训练不收敛 | 微调 lr（如 3e-4）或先检查数据/损失；不要轻易狂改 betas |
| 偏差校正在做什么 | 前几步 m、v 从 0 起步严重偏小，除以 (1-beta^t) 校准；别手动关掉它 |
| 与 SGD+Momentum 比快慢 | Adam 通常收敛更快且更稳；SGD+动量在小数据、精细调参时可更低 loss |
| 想"保守稳妥" | 多数深度学习任务无脑 Adam(lr=1e-3) 起步，是现代默认 |

@@point ⑥ 优化器选型与学习率调度
@@need 要解决什么
这么多优化器，实战到底用哪个？训练后期怎么进一步精细收敛？

@@idea 核心思路
**选型决策**：

| 场景 | 推荐 |
|---|---|
| 默认/通用（CNN、MLP） | **Adam(lr=1e-3)** |
| 数据少、要更低最终 loss | SGD + momentum(0.9)，配小 lr 精调 |
| 稀疏特征（如词向量/推荐） | Adagrad / Adam（自带自适应） |
| Transformer / 大模型、需要权重衰减 | **AdamW(lr=1e-3, weight_decay=0.01)**——Adam 的 L2 项会被 1/√v 缩放，做正则不干净 |

**学习率调度（Scheduler）**：训练后期用**衰减**让收敛更精细——先大步找到好区域，再小步在谷底精修：

```python
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=10, gamma=0.5)

for epoch in range(epochs):
    for xb, yb in loader:
        ...   # 训练五连
    scheduler.step()       # 每个 epoch 后调用，自动调低 lr
```

常用调度器：StepLR（每 N 轮乘 gamma，示例 gamma=0.5 即减半）、CosineAnnealingLR（余弦衰减）、ReduceLROnPlateau（loss 不降了再降 lr）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| scheduler.step() 忘调用 | lr 永远不衰减，调度器白设；明确每个 epoch 后调用 |
| 调度器把 lr 降到过小 | 衰减过头会训练停滞；检查 lr 曲线或设下限 |
| Adam 要不要配 scheduler | 可以，但 Adam 收敛本身稳，很多任务不配也行；SGD+动量配有效率更高 |
| 忘了 lr 是最重要的超参 | 90% 的不收敛问题先查 lr，其次才查模型和数据 |

@@point ⑦ 优化器超参速查：默认值就是好起点
@@need 要解决什么
每个优化器有哪些超参？第一次用该设什么？

@@idea 核心思路
一张速查表，覆盖绝大多数训练场景：

| 优化器 | 关键超参 | 推荐起点 |
|---|---|---|
| SGD | lr | 0.01 |
| SGD+Momentum | lr, momentum | 0.01, 0.9 |
| Adagrad | lr | 0.01 |
| RMSProp | lr, alpha | 0.001, 0.99 |
| Adam | lr, betas, eps | **0.001, (0.9, 0.999), 1e-8** |
| AdamW | lr, weight_decay | 0.001(或 3e-4), 0.01 |

**通用口诀**：
- 不熟悉的问题用 Adam(lr=0.001)，默认值出发基本能收敛。
- 收敛了想更精细（更低 loss）再试 SGD+momentum + lr 衰减。
- 一次只调一个超参，围绕起始值做 10 倍尺度缩放测试（lr 不收敛就 1e-3→1e-4）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 超参全是"默认"但结果差 | 默认值不是魔法；lr 与数据/模型匹配才是关键，主动试 1e-4~1e-1 |
| betas 想当然调 | beta2=0.999 是"长期记忆"；调小会更快响应近期梯度但更噪，多数情况别动 |
| AdamW 与 Adam 混用 weight_decay | AdamW 的权重衰减作用在参数本体（解耦）；Adam 的 weight_decay 直接加在梯度上，别混为一谈 |

@@point ⑧ 学习率预热与余弦退火：训练的两个阶段
@@need 要解决什么
训练前期优化器状态还没建立就大步走，后期又该慢慢"落位"，怎么安排？

@@idea 核心思路
**训练过程可以分"两段式"管理学习率**：

1. **预热（Warmup）**：前若干 step 让 lr 从小线性涨到目标值——早期梯度噪声大、优化器动量未建立，小步走更稳（Transformer 训练标配）。

2. **退火（Annealing）**：后期让 lr 从目标值平滑衰减到很小——先大步快速接近最优区域，再小步精修细节。

PyTorch 内置调度器一行可用：

```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer, T_max=50, eta_min=1e-6)   # 余弦退火：50 轮内降到 1e-6
```

配合使用：自定义 lambda 做前 10 步预热，再交给余弦退火收尾。**什么时候用**：小数据/短训练可不用；大规模训练（如 LLM、大 CNN）预热+退火几乎是标准配置。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 预热放错位置 | 预热发生在每个 batch 后（按 step），退火多在 epoch 后；两者频率不同是关键 |
| 退火后 loss 却上升 | eta_min 过低或退火太快；给足 T_max 或设下限 |
| 以为 scheduler 会自动生效 | 不会；必须在训练循环里显式调用 scheduler.step() |

一句话记住本章：**裸 SGD 震荡又怕平原；动量加惯性、自适应调步长，合起来就是 Adam——深度学习默认优化器 lr=0.001；训练后期用 scheduler 降学习率精修，大模型换 AdamW。**


@@summary
优化算法全貌：

| 优化器 | 核心机制 | 解决什么 | 一句话评价 |
|---|---|---|---|
| SGD | param -= lr*grad | 基线 | 简单但慢、震荡 |
| SGD+Momentum | 加"惯性"速度 | 峡谷震荡 | 震荡小、走得快 |
| Adagrad | 梯度平方和缩放 lr | 参数尺度不均 | 稀疏好，但 lr 趋零 |
| RMSProp | EWMA 平滑平方梯度 | Adagrad 停摆 | 自适应且不枯竭 |
| Adam | 动量 + RMSProp | 前两者痛点 | **默认标准** |
