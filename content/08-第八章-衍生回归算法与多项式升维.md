@@why 这一章在解决什么问题
上一章给了两件武器：归一化（治量纲）和正则化（治过拟合）。这一章把它们**组装成可用的完整算法**：普通线性回归的正则化衍生三兄弟——**Ridge（岭回归）、Lasso、ElasticNet**，外加工程味十足的 **SGDRegressor**。然后解决另一个大问题：**数据不是直线关系怎么办？** 答案是**多项式升维**——把特征 x 变成 x²、x³ 再送进线性模型，让"直线"弯起来。

@@point ① 为什么不做"普通线性回归 + 手写正则"
@@need 要解决什么
正则化公式上一章有了，为什么要单独学"衍生算法"，而不是自己改损失函数？

@@idea 核心思路
理论上改动很小（损失函数加惩罚项），但工程上有三个现实理由：
1. **解析解变化**：加了惩罚项后，正规方程变成 w* = (XᵀX + λI)⁻¹Xᵀy——多出的 λI 反而让 XᵀX 不可逆时也**能求逆**（正则化顺带修好了病态矩阵的数值问题）。
2. **求解方式不同**：L1 形式在 0 点不可导，没有简洁解析解，需要专用算法（坐标下降等）——sklearn 封装好了。
3. **生态成熟**：Ridge/Lasso 还有配套的自动调参（RidgeCV/LassoCV）与多种求解器，自研容易踩坑。

所以结论：**用封装好的衍生算法，而不是手拼正则**。这是"理解原理 → 使用成熟工具"的正确姿势。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 手写"LinearRegression + λΣw²"就以为等于 Ridge | 求解器、数值稳定性、API 都不同；**工程选型用官方 Ridge** |
| 期待 Ridge 结果和"手拼惩罚"完全一致 | 正常会有浮点级/收敛级小差异；宏观拟合行为一致即可 |

@@point ② Ridge 岭回归：L2 的完全体
@@need 要解决什么
Ridge 是谁、解决什么、怎么用？——它是加 L2 惩罚的线性回归，全场景通用。

@@idea 核心思路
```
Ridge 目标 = MSE + α·Σ w_j²
```
- **α（alpha）就是上一章的 λ**，惩罚强度；默认 alpha=1.0，常见从 1e-3~10 调。
- 效果：权重整体被压小、稳定、抗过拟合；所有特征都保留（不砍到 0）。
- 自带正则化的"副作用福利"：特征间高度相关（多重共线性）时，Ridge 的 λI 项让求解稳定，系数不会剧烈跳动。

使用（保险实战的配方）：
```python
from sklearn.linear_model import Ridge
reg = Ridge(alpha=10.0)
reg.fit(x_train, y_train)
```
**Ridge 是"无脑先试"的默认模型之一**：不出彩但永远稳定，适合当基准。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| alpha 用默认 1.0 到处跑 | 1.0 只是默认值；数据不同最优 α 不同，用 RidgeCV 自动选 |
| 忘了归一化就训 Ridge | 惩罚对量纲敏感，先 StandardScaler（上一章的纪律在此兑现） |

@@point ③ Lasso：L1 的特征选择器
@@need 要解决什么
什么时候用 Lasso？它和 Ridge 的分工边界在哪？

@@idea 核心思路
```
Lasso 目标 = MSE + α·Σ |w_j|
```
- L1 惩罚把**部分权重精确压成 0**——自动做特征选择（无用特征被"裁员"）。
- 适用场景：**特征多（上百上千）、怀疑大量无关特征**；压缩后得到稀疏、可解释的模型。
- 代价：特征高度相关时，Lasso 可能"乱点鸳鸯"（随机留一个砍另一个）；此时 ElasticNet 更稳。

使用与调参：
```python
from sklearn.linear_model import Lasso
lasso = Lasso(alpha=1e-3)
lasso.fit(x_train, y_train)
print(lasso.coef_)   # 会有很多 0
```
肉眼判断哪些特征被保留：看 `coef_` 非零项。这就是"可解释性"的直接体现。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 特征不多也用 Lasso 求"稀疏" | 特征是基本盘别乱裁；特征少且都有用时 Ridge 更合适 |
| alpha 太大，系数全被砍成 0 | λ 过强 = 全员失业；调小 alpha 或 ElasticNet |

@@point ④ ElasticNet：L1+L2 的合体
@@need 要解决什么
Lasso 砍特征但怕"乱砍"、Ridge 稳定但不砍——能不能既砍又稳？

@@idea 核心思路
**ElasticNet**：目标 = MSE + α·(r·L1 + (1-r)·L2)，两个超参数：
- **alpha**：总体惩罚强度。
- **l1_ratio**：L1 占比（0~1）。r=1 退化成 Lasso，r=0 退化成 Ridge。

优势：L2 的稳定性兜底 + L1 的稀疏性；特征超多且高度相关时，是比纯 Lasso 稳健的选择。
```python
from sklearn.linear_model import ElasticNet
en = ElasticNet(alpha=1e-3, l1_ratio=0.5)
en.fit(x_train, y_train)
```
**选型口诀**：简单问题 → Ridge；追求稀疏/特征选择 → Lasso；特征多且有相关性、要稳健 → ElasticNet。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为 ElasticNet 永远比单用好 | 多一个超参数多一份调参成本；数据简单时 Ridge 就够 |
| l1_ratio 设 0.5 当万能 | 0.5 是起点；嵌套交叉验证 GridSearchCV 里一起搜 alpha 和 l1_ratio |

@@point ⑤ SGDRegressor：梯度下降实现的正则回归
@@need 要解决什么
前面四个模型走的是解析解/坐标下降，数据量巨大时怎么办？——梯度下降版的线性回归来了。

@@idea 核心思路
```python
from sklearn.linear_model import SGDRegressor
sgd = SGDRegressor(max_iter=1000, tol=1e-3,
                   penalty='l2', alpha=0.01,   # penalty：l1/l2/elasticnet
                   learning_rate='invscaling') # 或 constant/adaptive
sgd.fit(x_train, y_train)
```
- **penalty** 参数选正则类型：'l2'（默认）=Ridge 风、'l1'=Lasso 风、'elasticnet'=混合。
- **alpha**：对应正则强度。
- 本质：用**随机梯度下降**（SGD，可 `partial_fit` 增量/在线训练）优化「损失 + 惩罚」，**能处理上亿样本、支持在线学习**。
- 用法口诀：**数据小用小样本套餐（Ridge/Lasso/ElasticNet），数据大、要在线学习用 SGDRegressor**。

这也回应了第 4-6 章的伏笔：梯度下降不是只属于"玩具"，它就是大数据正则回归的引擎。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| SGDRegressor 结果和 Ridge 差一点 | 梯度下降是迭代近似 + 有随机性；收敛到位后应接近，小差异正常（设 random_state 复现） |
| penalty 与归一化顺序弄反 | 老规矩：先 StandardScaler 再上 penalty，否则惩罚不公平 |

@@point ⑥ 多项式升维：为什么要"多此一举"
@@need 要解决什么
数据明明是弯曲的，线性模型画不了弯线。不换模型的前提下有没有办法让它"弯"？

@@idea 核心思路
核心 trick：**给特征增加幂次与交叉项，让线性模型在"高维空间"里拟合非线性关系**。
- 原始：y = w0 + w1·x（直线）
- 升维后：y = w0 + w1·x + w2·x² + w3·x³（对 x 的幂次加权 = 曲线！）

**重点**：模型对参数 w 仍是线性的（w 都是一次方）——所以第二章"线性"的定义依然成立，解析解/梯度下降照常适用。**用线性模型的求解器，拟合非线性的数据**，这就是"多项式回归"的巧劲。

上一章欠拟合的解法在这里兑现：模型太简单拟合不动弯曲数据 → 升维加复杂度。对应地，**阶数太高又回到过拟合**——degree 是又一个必须拿捏的超参数。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为升维=模型变成"非线性模型" | 参数仍线性，只是特征空间变胖了；**求解器没变，变的只有输入** |
| 一次升到 degree=10 炫耀"更准" | 训练误差很好看、测试误差暴涨 = 过拟合；degree 从小试起 |

@@point ⑦ PolynomialFeatures：代码里的升维
@@need 要解决什么
升维在 sklearn 里一行代码搞定，但有几个参数（include_bias 等）容易踩坑。

@@idea 核心思路
```python
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(degree=2, include_bias=False)
x_poly = poly.fit_transform(x)   # 把 [x1, x2] 变成 [x1, x2, x1², x1·x2, x2²]
```
- `degree=2`：生成所有 1~2 阶的幂次与交叉项。
- `include_bias=False`：**不生成常数 1 列**。因为后面模型自带截距（LinearRegression 的 fit_intercept=True）；若 include_bias=True 再配 fit_intercept=True，两列常数会撞车（冗余多重共线性）。
- 特征数爆炸提醒：n 个特征、degree=d，特征数约 C(n+d, d)。**10 个特征 degree=3 就上百维**——升维要克制。

使用纪律：**先切分（train/test），再对训练集 fit_transform、测试集只 transform**——poly 也是"看图学习"的预处理，参数（各阶组合规则）来自训练集。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| include_bias=True 且模型又 fit_intercept=True | 两列常数重复，特征冗余；**二选一：include_bias=False + 模型自带截距**（推荐） |
| 对测试集也 fit_transform | 训练/测试口径要一致，只对训练集 fit |

@@point ⑧ degree 的选择：欠拟合与过拟合的温度计
@@need 要解决什么
degree=1、2、3、10 分别发生什么？怎么选阶数？

@@idea 核心思路
同一组弯曲数据，不同 degree 的表现：
| degree | 表现 | 诊断 |
|---|---|---|
| 1 | 直线硬掰，训练/测试误差都高 | 欠拟合（模型太简） |
| 2~3 | 曲线贴合数据，训练/测试都低 | 刚好（推荐区间） |
| 10+ | 曲线穿过每个点，训练≈0、测试暴涨 | 过拟合（背答案） |

验证方法：**画出"degree vs 训练/测试误差"两条曲线**——测试误差出现"先降后升"的 V 形谷底，谷底对应的 degree 就是要选的值。

工程注记：degree 与正则化是配套的"油门与刹车"——升维加马力（degree 增大），正则化踩刹车（α 增大防飘）。真实项目常"高 degree + 强正则"组合使用。这也是 Ridge 在保险案例里配 degree=2 的来历（下一章实战）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 只调 degree 不管正则 | 高维必过拟合；degree 上去的同时 α 也要跟上 |
| 用测试集反复试 degree 直到"最好" | 反复看测试集调参 = 测试集也变成了训练集（间接过拟合）；严谨做法：再拆验证集或交叉验证 |

@@summary
本章装备升级完成：

| 算法 | 惩罚 | 特点 | 适用 |
|---|---|---|---|
| Ridge | L2 | 权重压小、稳定、保全部特征 | 通用默认基准 |
| Lasso | L1 | 权重砍到 0、自动选特征 | 特征多、求稀疏可解释 |
| ElasticNet | L1+L2 | 又砍又稳，l1_ratio 调比例 | 特征多且相关 |
| SGDRegressor | penalty 可选 | 梯度下降求解、可在线 | 大数据/在线学习 |
| PolynomialFeatures | 无 | 特征升幂加交叉项，让线变弯 | 数据非线性 |
| 配套纪律 | — | 先归一再正则；先切分再预处理 | 全程 |

一句话记住本章：**Ridge 用 L2 压小权重当稳定基准，Lasso 用 L1 砍特征求稀疏，ElasticNet 两个都要还能调比例，SGDRegressor 用梯度下降伺候海量数据；数据不直就多项式升维（degree 从小试、include_bias 关掉），升维加马力、正则踩刹车，这对组合是实践标配。**
