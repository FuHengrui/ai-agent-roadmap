@@why 这一章在解决什么问题
"深度学习"这个词满天飞，但很多人的理解是模糊的：它和人工智能、机器学习是什么关系？和传统机器学习差在哪？为什么现在写神经网络都要先装 PyTorch、TensorFlow 这种"框架"？这一章先把这三件事说透：**深度学习是什么、它和机器学习怎么分工、以及框架到底帮你干了什么活**。这些概念是后面所有章节的地基——不搞清楚，后面学 PyTorch 时你会不知道为什么非要用它。

@@point ① 深度学习与人工智能、机器学习的关系
@@need 要解决什么
"人工智能""机器学习""深度学习"三个词经常混着用，到底谁包含谁？

@@idea 核心思路
它们是**层层包含**的关系，像套娃：

- **人工智能（AI）**：最外层，让机器表现出智能行为的总目标。
- **机器学习（ML）**：实现 AI 的一种途径——不写死规则，而是让机器**从数据里学规律**。
- **深度学习（DL）**：机器学习的一个子集，用**模拟人脑的神经网络结构**做数据分析和模式识别。

一句话：**深度学习是实现机器学习的一种方法，机器学习是实现人工智能的一种途径。** 神经网络（NN）就是深度学习用来"学"的那个结构。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为"深度学习 = 人工智能" | 深度学习只是 AI 旗下的一条技术路线；规则系统、传统机器学习也都属于 AI |
| 把神经网络和深度学习划等号 | 神经网络是"结构"，深度学习是"用深度神经网络学习"的整套方法；单层感知机这种浅网络一般不算深度学习 |

@@point ② 传统机器学习与深度学习的流程对比
@@need 要解决什么
同样做一次预测，传统机器学习和深度学习的操作流程有什么不同？

@@idea 核心思路
传统机器学习流程是"人肉提特征"：

```
数据获取 → 数据预处理 → 特征提取(人工!) → 数据集划分
→ 模型选择与训练 → 模型评估 → 满意? 部署 : 调整超参数重来
```

深度学习的流程把"特征提取"这一环**交给了网络自己**：

```
数据获取 → 数据预处理 → 数据集划分
→ 深度神经网络构建与训练(自动特征提取) → 模型评估
→ 满意? 部署 : 调整超参数重来
```

两边的骨架几乎一样，唯一的本质差异就是：**特征提取是人工的还是自动的**。这也是深度学习最革命的一点。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为深度学习不需要任何预处理 | 数据清洗、归一化、数据集划分一步都不能少；变的一直是"特征提取"而非"数据准备" |
| 忽略了传统流程中特征工程的质量决定上限 | 传统 ML 中特征质量直接决定模型性能，这是它最吃专家经验的地方 |

@@point ③ 特征工程：人工 vs 自动
@@need 要解决什么
"自动特征提取"到底凭什么能赢过人工特征工程？

@@idea 核心思路
- **传统机器学习**：需要人工设计特征，依赖领域专家的经验与知识。特征质量直接影响模型性能，而设计好特征往往是最费力的环节。
- **深度学习**：能够**自动学习和提取特征**，大幅减少人工特征工程的工作量。在处理图像、语音、文本这类**非结构化数据**时优势尤其明显——没人能手工描述出一张图里"该看哪些像素"。

代价也很明确：深度学习通常需要**更多的数据和算力**，训练时间更长；但在数据量充足时，通常能得到更好的性能。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为深度学习完全不需要人工干预 | 只是特征提取自动化了；网络结构、超参数、数据质量仍高度依赖人的判断 |
| 在小数据集上硬上深度学习 | 数据不够时传统机器学习（甚至简单统计方法）往往更靠谱，深度模型容易过拟合 |

@@point ④ 深度学习的主要应用场景
@@need 要解决什么
学了深度学习能干什么？应用面有多宽？

@@idea 核心思路
深度学习的应用几乎覆盖所有行业：

| 领域 | 典型场景 |
|---|---|
| 智能医疗 | 影像辅助诊断、病理分析 |
| 智能汽车 | 自动驾驶感知、车道识别 |
| 智能安防 | 人脸识别、行为分析 |
| 智能零售 / 营销 | 商品识别、用户画像 |
| 智能教育 | 学情分析、作业批改 |
| 智能金融 | 风控、量化交易 |
| 智能客服 / 游戏 | 对话系统、NPC 决策 |
| 智能制造 / 农业 / 物流 / 能源 / 城市 | 质检、产量预测、调度、负荷预测 |

路数都一样：**把"人看一眼就能判断"的事，交给网络自动学**。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 觉得应用就是"图像识别 + 语音" | 只要是"数据 → 规律 → 预测/决策"的问题都可能是深度学习的菜；先想清楚任务类型（分类/回归/生成）再选模型 |
| 看到行业词就发怵 | 剥掉外壳全是熟悉的东西：分类、回归、聚类、序列预测。学通原理后换行业只是换数据集 |

@@point ⑤ 什么是深度学习框架
@@need 要解决什么
为什么写神经网络不能像写普通程序一样只用 Python 标准库？框架到底提供了什么？

@@idea 核心思路
**深度学习框架是一个软件工具集**，把构建、训练、部署神经网络所需的几乎所有基础设施打包好。核心能力四件套：

1. **自动微分系统**：自动计算梯度、支持反向传播，把最难的求导环节自动化。
2. **张量运算**：多维数组操作、GPU 加速支持、高效数学运算。
3. **神经网络组件**：预定义的卷积层、全连接层、激活函数、损失函数、优化器，拿来即用。
4. **数据处理工具**：数据加载、预处理、数据增强，衔接原始数据到模型。

有了框架，从**快速实验、模型原型设计、算法验证，到模型训练、服务部署、性能优化**全流程都能高效完成。没有框架时自己从零手写反向传播和 GPU 加速，光工程量就劝退绝大多数项目。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为框架只是"存数据的库" | 它的核心是自动微分 + 张量 + 网络组件；存储管理不是它的主业 |
| 以为框架只支持 CPU | 主流框架都深度支持 GPU 加速，CPU/GPU 只是运行后端的区别 |
| 以为自己写模型就不用框架 | 手写反向传播在玩具演示里可行，实际项目规模下是灾难；框架是标准答案 |

@@point ⑥ 主流框架对比：PyTorch 与 TensorFlow
@@need 要解决什么
市面上框架那么多，PyTorch、TensorFlow 到底选哪个？

@@idea 核心思路
两大主力各有特点：

| 框架 | 开发者 | 特点 | 适合谁 |
|---|---|---|---|
| **TensorFlow** | Google | 市场份额最大，跨语言跨平台，工业部署生态成熟，Keras 是其高级 API | 工业界大规模部署 |
| **PyTorch** | Facebook（Meta） | 简洁灵活，动态计算图，调试直观 | 学术界和研究，近年迅速流行 |
| **飞桨 PaddlePaddle** | 百度 | 中国首个自主研发的产业级框架，中文文档丰富，预训练模型多 | 国内产业落地、中文社区 |
| **Keras** | TensorFlow 生态 | 高级 API，快速开发和原型验证 | 快速上手 |
| **MXNet** | Apache | 曾有一定中国市场 | 部分金融科技公司 |

现实中很常见的路线是：**研究用 PyTorch 快速验证想法，落地时按部署栈选择**。本课程的主线就是 PyTorch。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 纠结"哪个最好"而迟迟不开始 | 框架只是工具，原理通用；本阶段用 PyTorch 一条线学透，思想可迁移到任何框架 |
| 以为 TensorFlow 和 PyTorch 写起来天差地别 | 核心概念（张量、自动微分、层、优化器）一一对应，换个框架主要是 API 换皮 |

@@point ⑦ 飞桨：国产框架的代表
@@need 要解决什么
除了两大巨头，国产框架飞桨（PaddlePaddle）为什么值得了解？

@@idea 核心思路
飞桨由百度开发和维护，是中国首个自主研发的深度学习框架，服务超过 470 万开发者、15.7 万家企业。特点：

- **完整的产业级框架**：从研究到落地全流程。
- **丰富的中文文档和教程**：学习门槛低。
- **针对中国开发者优化**：生态贴近国内场景。
- **大量预训练模型**：即拿即用，适合快速落地。

在企业级项目、国产化选型等场景里，飞桨是个重要候选。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为框架只有外国做的 | 国产框架已相当成熟，选型时按团队生态和部署环境定，不必迷信某一方 |
| 学了一门就不认其他框架 | 课程代码以 PyTorch 为主，但概念通用；遇到别家框架看懂文档就能上手 |

@@point ⑧ 本阶段的学习路线：从框架到实战
@@need 要解决什么
明确了"深度学习是什么、框架是什么"之后，接下来怎么一步步学会？

@@idea 核心思路
本阶段的推进路线非常清晰：

1. **打好地基**：PyTorch 安装与核心库（本章之后立即开始）。
2. **学会数据结构**：张量的创建、运算、形状变换——神经网络的"数字积木"。
3. **打通训练闭环**：自动微分 → 模型构建 → 损失函数 → 优化器 → 训练循环。
4. **进化的武器**：激活函数、正则化（Dropout/BN）、先进优化算法（Adam 等）。
5. **完整实战**：用全连接网络做乳腺癌二分类，把前面所有知识串成一条流水线。
6. **读论文**：精读 Faster R-CNN，理解框架之上的研究思维。

每一章都是在为下一章"喂材料"，跟着走完，你就有能力独立搭一个能用的神经网络。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 跳过张量直接想写模型 | 模型代码里每个数据都是张量，运算、形状不对会处处报错；地基必须稳 |
| 只抄代码不抠原理 | 网络会报错、效果会不好，没有原理只能瞎猜；每章重视"为什么" |

@@summary
本章把深度学习放进了全景图里定位：

| 问题 | 答案 |
|---|---|
| 三者的关系 | AI ⊃ 机器学习 ⊃ 深度学习（神经网络是其核心结构） |
| 和传统 ML 的流程差异 | 特征提取：人工 → 自动；骨架流程一致 |
| 深度学习的特点 | 自动学特征、适合非结构化数据、要更多数据算力、性能上限高 |
| 应用范围 | 医疗/汽车/安防/金融/客服等，本质都是"数据→规律→决策" |
| 框架是什么 | 自动微分 + 张量运算 + 网络组件 + 数据工具的集合 |
| 主流框架 | TensorFlow（工业）、PyTorch（研究）、飞桨（国产）、Keras（快速原型） |
| 本阶段路线 | 张量 → 自动微分 → 模型/损失/优化 → 正则化 → 实战 → 读论文 |

一句话记住本章：**深度学习是 AI 里靠神经网络自动学特征的路线，框架（如 PyTorch）把这套流程的基础设施全部打包好了，接下来就是学会怎么用它。**
