@@point ① Python 程序的构成
@@need 要解决什么
你写了一个 `.py` 文件，它到底是怎么被执行的？**搞清楚这个，你才知道代码该往哪写、为什么会报"语法错误"。**
@@idea 核心思路
一个 Python 程序从大到小分四层：

| 层级 | 是什么 | 例子 |
| **模块** | 一个 `.py` 文件就是一个模块 | `chat.py` |
| **语句** | 一行可执行的指令 | `print("hi")` |
| **表达式** | 能算出一个值的东西 | `1 + 2`、`len("abc")` |
| **对象** | 程序里所有"数据" | 数字、字符串、列表……**一切皆对象** |

执行的顺序是**从上往下一行一行来**（后面学了函数、循环会有跳转，但基础是顺序执行）。

Python 的一个特点是**不需要写分号、不需要写 main 函数**，直接写语句就行——这就是它"短"的原因之一。
@@trap 两个容易混淆的点
| 现象 | 说明 |
| 一个文件能不能当成程序跑？ | 能。但一个模块被别的文件 `import` 时，**里面的顶层代码也会被执行一遍**。所以常写 `if __name__ == "__main__":` 把"只有在直接运行时才执行"的代码圈起来 |
| 语句和表达式怎么分？ | 表达式**有值**（`1+2` 的值是 3），语句**做事**（`print(...)` 是做事）。`print(...)` 是函数调用表达式，值恒为 `None`，特点是**有副作用**（会打印） |

@@point ② 对象、引用与内存模型 ★
@@need 要解决什么
这是整个 Python 里**最该先搞懂的一件事**。很多新手被"改了 b 结果 a 也变了"折磨到怀疑人生，根源就在这里。
@@idea 核心思路
三个事实，记住就够：

- **一切皆对象**：数字、字符串、函数、类，全是对象
- **对象有三个要素**：`id`（身份，相当于内存地址）、`type`（类型）、`value`（值）
- **变量不是盒子，是标签**：`a = 3` 不是"把 3 装进 a"，而是"**把 a 这个标签贴到 3 这个对象上**"

用图理解：

```cmd
#    变量名            内存里的对象（堆）
#  ┌────────┐        ┌──────────────┐
#  │   a    │──────▶ │ id=1402...   │
#  └────────┘        │ type=int     │
#                    │ value=3      │
#                    └──────────────┘
```

**关键推论**：如果两个变量指向**同一个对象**，通过其中一个改了这个对象，另一个看到的内容也跟着变。

```python
a = [1, 2]
b = a          # b 和 a 指向同一个列表对象
b.append(3)
print(a)       # [1, 2, 3]  ← a 也变了！
```

**那什么情况下不会互相影响？** 当赋值产生的是**新对象**时：

```python
a = 3
b = a          # 此时 a、b 都指向 3（小整数会被复用）
b = b + 1      # b+1 产生【新对象】4，b 改贴到 4 上
print(a)       # 3  ← a 没变
```

**区别在哪**：`b.append(3)` 是**原地修改对象**；`b = b + 1` 是**造了个新对象**。前者会牵连别人，后者不会。
@@trap 怎么快速判断会不会互相影响
| 类型 | 能不能原地改 | 例子 |
| **不可变**（int / float / str / tuple） | ❌ 不能 | 改它必然产生新对象，不会牵连别人 |
| **可变**（list / dict / set） | ✅ 能 | 用 `.append()` `.update()` 这类方法会就地改，**会牵连所有指向它的变量** |

看函数参数时尤其要小心——传进去的是可变对象，函数里改了，外面也变。

@@point ③ 标识符与命名规则
@@need 要解决什么
变量、函数、类都得起名字。名字起错了程序直接报 `SyntaxError`；名字起得烂，三个月后你自己看不懂。
@@idea 核心思路
**硬规则**（不遵守就报错）：

- 只能用**字母、数字、下划线**，且**不能以数字开头**
- **区分大小写**：`Name` 和 `name` 是两个东西
- **不能是关键字**：`if`、`for`、`class`、`def`、`None`、`True` 这些不能当名字

**软规范**（不遵守不报错，但会被同事嫌弃）：

| 对象 | 约定 | 例子 |
| 变量、函数 | 全小写 + 下划线 | `user_name`、`get_data()` |
| 常量 | 全大写 | `MAX_SIZE`、`API_URL` |
| 类名 | 大驼峰 | `ChatBot`、`JobItem` |
| "私有"的 | 前面加一个下划线 | `_internal` |

**还有一条经验**：名字要**能看出是什么**。`a1`、`temp`、`data2` 这种名字是负债——两周后你完全想不起它是什么。
@@trap 别用内建名字当变量名
`list = [1,2]`、`str = "abc"`、`sum = 0` 这种写法不报错，但**会把 Python 内置的类型和函数覆盖掉**，后面用 `list()` 就会炸。名字前面加个下划线或换个名都行。

@@point ④ 变量、常量与赋值
@@need 要解决什么
程序要处理数据就得先"存起来"。Python 的赋值有一堆好用的写法，**学会了能少写很多行**。
@@idea 核心思路
**变量**：Python 是**动态类型**——变量不需要声明类型，赋什么值就是什么类型，而且**可以中途换类型**。

```python
x = 10          # x 指向一个 int
x = "hello"     # 现在 x 指向一个 str，完全合法
```

**常量**：Python **没有真正的常量**（语法上不禁止你改）。约定用全大写表示"这是常量，别改"：

```python
MAX_RETRY = 3   # 靠自觉，不是靠语法
```

**三种好用的赋值写法**：

```python
# 1. 链式赋值
a = b = c = 0

# 2. 系列解包赋值（数量必须对上，否则 ValueError）
x, y, z = 1, 2, 3
x, y = y, x              # 一行交换两个变量，不用临时变量

# 3. 用 * 收集剩下的（后面章节会讲）
first, *rest = [1, 2, 3, 4]
```

**垃圾回收**：Python 会**自动回收没人引用的对象**，你不用手动释放内存。

```python
a = [1, 2, 3]
a = None        # 原来的列表没人引用了 → 被回收
```

机制是**引用计数**为主、**标记清除 + 分代回收**为辅。你不需要手动管，但要理解：**只要还有变量指向它，它就不会被回收。**
@@trap 解包赋值的数量陷阱
`x, y = 1, 2, 3` 会报 `ValueError: too many values to unpack`。**数量必须严格相等**（除非用 `*` 收集）。这是新手很常见的一类错误。

@@point ⑤ 内置数据类型与算术运算符
@@need 要解决什么
你得知道 Python 有哪些"数据种类"，才能选对工具。**用字符串存价格、用列表存一个人**，这类错误后面会一直折磨你。
@@idea 核心思路
**最常用的六种内置类型**：

| 类型 | 字面量写法 | 说明 |
| `int` | `42`、`0b1010`、`0o17`、`0xFF` | 整数，**无限精度**（不会溢出） |
| `float` | `3.14`、`1.5e3` | 浮点数，**有精度误差** |
| `str` | `"abc"`、`'abc'`、`"""abc"""` | 字符串 |
| `bool` | `True`、`False` | 布尔值，其实是 int 的子类 |
| `list` | `[1, 2, 3]` | 列表（第三章） |
| `dict` | `{"k": "v"}` | 字典（第三章） |

**算术运算符**：

```python
7 + 2      # 9      加
7 - 2      # 5      减
7 * 2      # 14     乘
7 / 2      # 3.5    除 —— 【结果永远是 float】
7 // 2     # 3      整除（向下取整）
7 % 2      # 1      取余
7 ** 2     # 49     幂
```

**两个必须记住的**：

- `/` 和 `//` 不一样：`7 / 2` 是 `3.5`，`7 // 2` 是 `3`
- `%` 取余不只是算数学，**判断奇偶、循环轮转、哈希**都靠它：`n % 2 == 0` 就是偶数
@@trap 整数除法 vs 浮点
| 写法 | 结果 | 说明 |
| `7 / 2` | `3.5` | 真除法，**永远返回 float** |
| `7 // 2` | `3` | 整除，两个 int 相除仍是 int |
| `-7 // 2` | `-4` | **向下取整**，不是向零取整。这个坑很多人踩 |

@@point ⑥ 数字：整数、进制与浮点数
@@need 要解决什么
程序里凡是涉及钱、时间、坐标，都和数字打交道。**浮点数有个精度陷阱，不知道的话算钱会算错。**
@@idea 核心思路
**整数与进制**——同一个数可以有四种写法：

```python
10          # 十进制
0b1010      # 二进制（0b 开头）
0o12        # 八进制（0o 开头）
0xA         # 十六进制（0x 开头）
```

转换用内置函数：`bin(10)` → `'0b1010'`，`int("0b1010", 2)` → `10`，`int("ff", 16)` → `255`。

**浮点数与精度陷阱**——这是必须记住的：

```python
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False  ← ！？
```

原因：计算机用二进制存小数，**0.1 和 0.2 在二进制里是无限循环小数**，存进去就被截断了。

**所以绝对不要用 `==` 比较两个浮点数。** 正确做法：

```python
abs(a - b) < 1e-9             # 差足够小就认为相等
```

涉及钱建议用 `decimal.Decimal`（后面章节会提）。

**类型转换**：

```python
int(3.99)      # 3     ← 注意是【截断】不是四舍五入！
round(3.99)    # 4     这才是四舍五入
float("3.14")  # 3.14
str(123)       # "123"
```
@@trap 三个高频坑
| 坑 | 说明 |
| `int(3.99)` 得到 `3` | `int()` 是**截断小数**，不是四舍五入。要四舍五入用 `round()` |
| `0.1 + 0.2 != 0.3` | 浮点精度问题，用误差范围比较 |
| `1e3` 是什么 | 科学计数法，等于 `1000.0`。**是 float 不是 int** |

@@point ⑦ 时间的表示与 time 模块
@@need 要解决什么
程序经常要处理"多久以前""三天后""这条记录是什么时候的"。**时间在计算机里其实就是一个数字。**
@@idea 核心思路
计算机里的时间原点叫 **Unix 纪元（Epoch）**：**1970 年 1 月 1 日 00:00:00 UTC**，从那时刻起过了多少秒，就是"时间戳"。

```python
import time

time.time()            # 1758888888.123   ← 当前时间戳（秒，带小数）
```

带小数的部分是**毫秒/微秒**。这也是为什么计算耗时都用它：

```python
start = time.time()
# ... 要测的代码 ...
print("耗时 %.3f 秒" % (time.time() - start))
```

**常用转换**：

```python
time.localtime()                    # 转成本地时间结构体
time.strftime("%Y-%m-%d %H:%M:%S")  # 格式化成字符串
time.sleep(1.5)                     # 睡 1.5 秒（做限速、等页面加载常用）
```

**为什么 AI 应用里经常见到 `time.sleep`？** 因为抓网页要限速——请求太快会被封。
@@trap 时区与本地时间
`time.time()` 是 **UTC 时间戳**（全球统一），而 `time.localtime()` 会**转成你电脑的时区**。跨时区协作时，**存时间戳，展示时再转本地**，这样不会乱。

@@point ⑧ 布尔值与运算符
@@need 要解决什么
程序要做判断——"如果余额够就下单"。判断的结果就是布尔值。**这一节是下一章 `if` 语句的地基。**
@@idea 核心思路
**布尔值只有两个**：`True` 和 `False`（**首字母大写**）。

**三个容易搞混的运算符家族**：

| 家族 | 符号 | 干什么 |
| **比较运算符** | `==` `!=` `>` `<` `>=` `<=` | 比大小，返回布尔值 |
| **逻辑运算符** | `and` `or` `not` | 组合条件 |
| **位运算符** | `&` `\|` `^` `~` `<<` `>>` | 按二进制位操作 |

**别把 `and` 和 `&` 搞混**——这是新手最常见的错误之一：

```python
x = 5
print(x > 0 and x < 10)   # True   ← 逻辑与，正确写法
print(x > 0 & x < 10)     # x=15 时也打 True；正确写法 x > 0 and x < 10 才是 False
```

**短路运算**（很重要，也是常考的）：

```python
# and：左边为假，右边【根本不会执行】
result = (0 and 1/0)      # 返回 0，不会报除零错误

# or：左边为真，右边【根本不会执行】
name = user_input or "匿名"   # 输入为空就用默认值，这是个常用技巧
```

**真值判断**：任何对象都能当条件用。以下这些算 `False`：

```python
False, None, 0, 0.0, "", [], {}, set()
```

**其余都算 `True`**。所以 `if my_list:` 就是"列表非空"的简写。
@@trap 优先级与括号
`and` 优先级高于 `or`，位运算符又高于比较运算符——**记不住就加括号**。加括号不丢人，写出有歧义的代码才丢人。

@@point ⑨ is 与 == 的区别
@@need 要解决什么
新手经常看到 `is` 和 `==` 都能"比较"，随手混用。**它们比的根本不是一回事**，混用会出诡异 bug。
@@idea 核心思路
一句话记住：

- **`==` 比的是「值」** —— 两个对象内容一样就 True
- **`is` 比的是「身份」** —— 必须是**同一个对象**（id 相同）才 True

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)    # True   ← 内容一样
print(a is b)    # False  ← 不是同一个对象
print(a is c)    # True   ← c 就是 a
```

**什么时候该用 `is`？** 基本只有一个场景：**判断是不是 `None`**。

```python
if result is None:      # ✓ 推荐
if result == None:      # ✗ 能用但不推荐
```

**为什么推荐 `is None`？** 因为 `None` 全局只有一个对象，`is` 判断最快最准；而且如果某个类重写了 `__eq__`，`== None` 可能得到意外结果。
@@trap 小整数缓存的假象
```python
a = 256; b = 256
print(a is b)     # True   ← 小整数（-5~256）被缓存复用

a = 257; b = 257
print(a is b)     # 可能 True 也可能 False（取决于实现）
```
**所以永远不要用 `is` 比较数字或字符串的值**，那是 `==` 的活。

@@point ⑩ 字符串（一）：编码、创建、转义、输入
@@need 要解决什么
**AI 应用里处理的全是文本**——提示词是字符串、模型回答是字符串、要抓的网页也是字符串。**字符串是日常编程里最核心的数据类型。**
@@idea 核心思路
**先理解编码**：计算机只认数字，字符要靠"编码表"映射。Python 3 的字符串是 **Unicode**，所以中文、emoji 都能直接用。

**三种创建方式**：

```python
s1 = 'abc'              # 单引号
s2 = "abc"              # 双引号（和单引号完全等价）
s3 = """第一行
第二行"""                # 三引号：可以跨行，也常用作多行注释
```

**转义字符**（反斜杠 + 字母）：

| 写法 | 含义 |
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\\` | 一个反斜杠 |
| `\'` `\"` | 引号本身 |

不想让转义生效，用 **原始字符串** `r"..."`：

```python
print("C:\new")     # 换行了！\n 被解释成换行
print(r"C:\new")    # C:\new  ← r 开头，原样输出
```

**拼接与复制**：

```python
"hello" + " " + "world"    # 拼接
"ab" * 3                   # 'ababab'   ← 字符串复制
```

**从键盘读输入**——`input()` **永远返回字符串**：

```python
name = input("请输入名字：")
age = int(input("请输入年龄："))   # 要数字必须自己转
```
@@trap input 的返回值
`input()` 拿到的是**字符串**。`input()` 输入 `18`，你拿到的是 `"18"` 不是 `18`。做算术前必须 `int()` 或 `float()` 转一下——这是新手第一个必踩的坑。

@@point ⑪ 字符串（二）：下标与切片
@@need 要解决什么
"取前 100 个字喂给模型"、"去掉末尾的换行"、"判断是不是以 http 开头"——这些全是**取子串**的操作。
@@idea 核心思路
**下标**：字符串是**有序**的，每个字符有编号，**从 0 开始**。

```python
s = "Python"
#     P  y  t  h  o  n
#     0  1  2  3  4  5      ← 正向下标
#    -6 -5 -4 -3 -2 -1      ← 反向下标
```

**切片**：`s[起点:终点:步长]`

```python
s = "Python"
s[0:3]      # 'Pyt'      ← 含头不含尾！取 0、1、2
s[:3]       # 'Pyt'      ← 省略起点 = 从 0 开始
s[3:]       # 'hon'      ← 省略终点 = 到末尾
s[-3:]      # 'hon'      ← 最后三个
s[:]        # 'Python'   ← 完整拷贝
s[::-1]     # 'nohtyP'   ← 逆序（常用技巧！）
s[::2]      # 'Pto'      ← 每隔一个取
```

**"含头不含尾"是必须记住的**——`s[0:3]` 取的是 3 个字符，不是 4 个。这样设计的好处是 `s[:i] + s[i:]` 永远等于 `s`。
@@trap 切片不会报越界
```python
s = "abc"
s[10]        # IndexError！单取下标越界会报错
s[10:20]     # ''       切片越界【不报错】，返回空串
```
**这个特性很有用**（取前 100 字不用担心字符串不够长），但也容易掩盖 bug——取出来是空串时要想想是不是范围写错了。

@@point ⑫ 字符串（三）：常用方法与格式化
@@need 要解决什么
实际写代码时，90% 的字符串操作都是那十来个方法。**记住它们，效率提升巨大。**
@@idea 核心思路
**查找与判断**：

```python
s = "Hello World"
s.find("World")        # 6        找不到返回 -1（不报错）
s.index("World")       # 6        找不到【报错】
s.startswith("Hello")  # True
s.endswith("ld")       # True
s.count("l")           # 3
"World" in s           # True     成员判断，最常用
```

**清洗与大小写**：

```python
"  hi  ".strip()       # 'hi'      去首尾空白（**处理 input 必用**）
"xxhixx".strip("x")    # 'hi'      去指定字符
"Hi".lower()           # 'hi'
"hi".upper()           # 'HI'
"a,b,c".replace(",", "-")  # 'a-b-c'
```

**分割与合并**（处理数据时最常用的一对）：

```python
"a,b,c".split(",")          # ['a', 'b', 'c']
"-".join(['a', 'b', 'c'])   # 'a-b-c'
"  a  b  ".split()          # ['a', 'b']   不带参数 = 按任意空白分割，自动去空
```

**注意**：`"".join(list)` 比 `for` 循环 `+=` 拼接**快一个数量级**。因为字符串不可变，每次 `+=` 都要造新对象。

**格式化**——把变量嵌进字符串，三种写法：

```python
name, age = "小明", 18

# 1. f-string（**首选**，Python 3.6+）
f"{name} 今年 {age} 岁"
f"{3.14159:.2f}"        # '3.14'   保留两位小数
f"{0.856:.1%}"          # '85.6%'  百分比

# 2. format()
"{} 今年 {} 岁".format(name, age)

# 3. % 老写法（见到要认识，但别主动用）
"%s 今年 %d 岁" % (name, age)
```
@@trap 字符串不可变
```python
s = "abc"
s[0] = "A"        # TypeError！字符串不支持原地修改
s = "A" + s[1:]   # 正确做法：造一个新字符串
```
**推论**：循环里频繁拼接字符串（`s += x`）效率很低。要先收集到列表，最后 `"".join(list)`。

@@point ⑬ 类型转换总结
@@need 要解决什么
从 `input()` 拿到的永远是字符串，从 JSON 拿到的可能是数字也可能是字符串——**不做类型转换，程序迟早崩**。
@@idea 核心思路
**最常用的四个转换函数**：

```python
int("123")        # 123       字符串→整数
int(3.99)         # 3         浮点→整数（截断）
float("3.14")     # 3.14
str(123)          # '123'     任何东西→字符串
bool(0)           # False
```

**判断类型用 `type()`**：

```python
type(123)              # <class 'int'>
type(123) is int       # True     ← 推荐这样判断
isinstance(123, int)   # True     ← 还能判断子类，更通用
```

**显式转换 vs 隐式转换**：

```python
1 + 2.5        # 3.5   ← int 自动升级成 float（隐式）
"1" + 2        # TypeError！字符串和数字不能相加（Python 不做隐式转换）
```
@@trap 转换失败的场景
```python
int("abc")       # ValueError
int("3.14")      # ValueError ← 注意！带小数点的字符串不能直接 int
int(float("3.14"))  # 3  要两步
int("")          # ValueError
```
**所以从用户输入转换时一定要套 `try/except`**——这是第七章（异常机制）要解决的事，先留个印象。

@@summary
这一章你实际拿到的是**三样东西**：

| 拿到了什么 | 为什么要紧 |
| **一套"看穿代码"的模型** | 知道变量是标签不是盒子、对象分可变与不可变——后面所有诡异 bug 都能用这个解释 |
| **一套处理文本的工具** | 切片、split/join、f-string、strip——**AI 应用里天天用**，写提示词、清洗模型输出全靠它们 |
| **一堆必须记住的坑** | 浮点精度、`input` 返回字符串、`int()` 是截断、字符串不可变、`is` 与 `==` 的区别 |
