@@point ① 量化的定义：换一种更省的数值表示
@@need 要解决什么
"量化"具体是把模型里的数字变成什么？

@@idea 核心思路
**量化（Quantization）**：用**低精度**的数值类型表示模型的权重与激活，替代原始的 32 位浮点。

常见映射关系：

```
FP32 (4字节) → FP16 (2字节) → INT8 (1字节) → INT4 (0.5字节)
  [原始]          [半精度]      [定点]          [极低比特]
```

量化后模型依然"是同一个模型"（结构不变、推理逻辑不变），只是数字的表示精度变低了。关键认知：**量化不是重训一个新模型，而是给现有模型"换个更省的存储尺码"**，这是它与蒸馏的本质区别。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为量化=重新训练 | 量化是在已训好的模型上做数值变换，除非用 QAT（下一章）配合训练 |
| 混滑量化与剪枝 | 剪枝删结构，量化换表示，两者独立可叠加 |

@@point ② 量化的四大收益
@@need 要解决什么
把数字换成低精度，具体能得到什么？

@@idea 核心思路
量化的收益是**全方位**的：

1. **模型体积变小**：FP32→INT8 直接 4 倍缩小，传输/存储成本大降。
2. **内存占用下降**：权重与激活都省显存，大模型更容易塞进单卡。
3. **计算更快**：整型运算（INT8）比浮点运算快得多（硬件 ALU 吞吐更高），延迟与吞吐双赢。
4. **功耗降低**：定点/低比特计算的能耗远低于高精度浮点，利于边缘与移动端。

对应第一章的两把尺子：体积（压缩率）与速度（理论加速比）同时受益，且量化**不需要稀疏硬件**，普通 GPU/CPU 都能直接吃红利——这正是它"工业第一主力"的原因。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 以为量化只省体积 | 量化同时省体积、内存、计算、功耗，四维收益 |
| 量化后还想完全相同 | 低精度必然引入数值误差，目标是"精度损失可接受"，不是零损失 |

@@point ③ 量化对象：权重 + 激活
@@need 要解决什么
量化到底量化模型里的哪些"数字"？

@@idea 核心思路
模型的推理计算涉及两类数值：

- **权重（Weights）**：模型参数，训练完就固定，量化时"离线统计分布"方便。
- **激活（Activations）**：推理过程中的中间结果，每层都在变，分布动态、难精准统计。

因难易不同，量化策略分档：

| 策略 | 内容 | 难度 |
|---|---|---|
| 只量化权重 | 激活保持浮点 | 简单，收益打折 |
| 权重+激活都量化 | 全整数推理，收益最大 | 较难（激活校准） |

**"全整数量化"**就是权重与激活全部用 INT8/INT4，推理全程无浮点——目标硬件的吞吐与功耗最优，但对校准要求最高。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 只量化权重就宣称"已量化" | 激活才是推理运算大头，只有权重量化收益有限 |
| 忽略激活动态分布 | 激活每层分布不同且随输入变化，校准不好精度崩，必须有校准环节 |

@@point ④ K-means 聚类量化：用"码本"压缩权重
@@need 要解决什么
系数很接近的权重，为什么不能共享一份表示？K-means 量化怎么做的？

@@idea 核心思路
**K-means 聚类量化**（韩松 Deep Compression 论文核心）思路：**很多权重的值很接近，可以用少量"代表值"（码字）近似它们**。

实现步骤：

```
1. 把一层的所有权重当作数据点
2. 用 K-means 聚类成 k 个簇（k=2^bit，如 bit=8 → 256簇）
3. 每个簇的中心（均值）作为"码字"
4. 每个权重用"自己所属簇的编号"替代（只需 bit 位）
5. 预测时查询码本：索引 → 码字，得到近似权重
```

**收益**：权重不再存数值而存"索引"。例如 256 个码字，每个权重只需 8bit 就能找到自己的代表值，配合码本共享，压缩比大幅提升；码字还可以用微调进一步优化。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 内部比较时漏掉"码本也要存" | 码本本身占空间，要计入总存储（只是占比很小） |
| 误以为聚类后精度必然损失大 | 聚类质心接近原始值分布中心，配合微调可把损失压到很小 |

@@point ⑤ K-means 与均匀线性量化的关系
@@need 要解决什么
聚类量化和"把区间等分"的线性量化有什么异同？

@@idea 核心思路
两类量化可对比理解：

| 维度 | K-means 聚类量化 | 均匀线性量化 |
|---|---|---|
| 码字分布 | 由数据聚类决定（非均匀） | 固定等距（均匀） |
| 表示方式 | 索引查码本 | 整数 = 浮点/缩放因子 |
| 实现复杂度 | 较高（需聚类+码本） | 低（一条公式） |
| 适用 | 权重离线量化 | 权重+激活，硬件友好 |

**核心差异**：聚类量化是"数据自适应"的——值密集的地方码字密；线性量化是"均匀切分"——不管数据分布，全程等分。线性量化因为结构简单、硬件支持好，是工业主流；聚类量化离线做权重压缩时表现优秀。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 认为聚类量化是"更高级的线性量化" | 两者坐标系不同：聚类=查表，线性=公式换算，混为一谈会拉偏理解 |
| 忽略硬件兼容性 | 聚类量化产出码本+索引，很多硬件不直接支持，落地需转换层 |

@@point ⑥ 为什么量化能保持精度：数值误差的容忍度
@@need 要解决什么
把权重换精度，凭什么模型还"认得路"？

@@idea 核心思路
背后是**神经网络的鲁棒性与容错性**：

- **冗余性**：大量权重小幅扰动，对整体输出影响小（和剪枝有效性同源）。
- **误差集中在尾数**：量化误差是"近似误差"，权重均值、激活均值受影响有限；且激活后接非线性层会"消化"小误差。
- **互补性**：权重误差与激活误差往往部分抵消，而不是简单叠加。

但误差并非免费：位宽过低（如 INT2）或层数极深时误差会累积放大，导致输出质量骤降——这正是"校准"与"训练时量化"要解决的问题（下一章）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 认为量化误差=无误差 | 误差存在且随位宽降低放大，尤其深网络/长序列场景 |
| 用权重误差判断整体影响 | 要衡量的是"量化前后模型输出的差异"，不是权重的绝对误差 |

@@point ⑦ 量化与剪枝的自然组合
@@need 要解决什么
剪枝完再量化，为什么"1+1>2"？

@@idea 核心思路
剪枝与量化**作用维度正交**，可完美叠加：

```
剪枝：把参数"数量"变少（删冗余）
量化：把参数"表示"变省（换精度）
原理上: 先剪枝（参数少了）→ 再量化（每个参数更省）→ 双倍压缩
```

典型管线：**剪枝（稀疏化）→ 聚类/线性量化 → 微调**。要特别强调："剪枝、聚类量化、协同优化"的配合正是这套链路。收益示例：FP32 权重先剪掉 80% 再量化到 INT8，体积理论上缩小 4 倍 × 5 倍 = 20 倍（理想情况）。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 叠加后一步到位不做验证 | 剪枝+量化误差叠加可能超预期，每步之间都要验证精度 |
| 忽略"协同优化"设计 | 组合方案的效果依赖两者的调度与微调策略，不是简单 pipeline 拼接 |

@@point ⑧ 本章小结：量化的第一性认知
@@need 要解决什么
学完本章，量化的核心认知是什么？

@@idea 核心思路
用一句话骨架收拢：

```
量化 = 用低精度表示替代FP32（FP16/INT8/INT4）
收益 = 体积↓ 内存↓ 速度↑ 功耗↓（无需稀疏硬件）
对象 = 权重（好量化）+ 激活（难量化，需校准）
主流方法 = K-means聚类量化（查表） / 线性量化（公式）
可用性 = 网络冗余容忍误差；误差随位宽降而放大
组合 = 剪枝 + 量化 正交叠加，协同优化
```

下一章进入量化"最硬核"的部分：线性量化的数学公式、对称/非对称、校准技术，以及训练时量化 PTQ/QAT 的取舍。

@@trap 坑在哪
| 现象 | 原因 / 怎么办 |
|---|---|
| 跳过概念直接套工具 | 不理解 K-means/线性量化的原理，用 AWQ/GPTQ 等工具时只能瞎调参 |
| 忘记量化的"误差账" | 量化收益很香，但每降一位都要算精度账，工业实践靠校准控制 |

@@summary
这一章打好了量化的地基：

| 要点 | 内容 |
|---|---|
| 量化定义 | 用低精度表示（FP16/INT8/INT4）替代 FP32 |
| 四大收益 | 体积、内存、速度、功耗全优化 |
| 量化对象 | 权重（易）与激活（难，需校准） |
| K-means聚类量化 | 聚类得码本，权重存索引，查表还原 |
| 精度可保持 | 网络冗余容忍误差，但位宽低误差累积 |
| 与剪枝叠加 | 维度正交，剪枝×量化=组合压缩，需协同优化 |

一句话记住本章：**量化就是用 FP16/INT8/INT4 等低精度表示替代 FP32——一次获得体积、内存、速度、功耗四重收益且无需稀疏硬件，所以是工业第一主力；量化对象包括权重（好处理）和激活（难处理需要校准）；K-means 聚类量化把相近权重聚成码本、权重只存索引来压缩，而误差之所以可控是因为神经网络对小幅扰动天然鲁棒，只是位宽越低误差越大——下一章学线性量化和校准怎么控制这笔误差账。**
