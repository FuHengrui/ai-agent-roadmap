## 五、这套东西里最值得复用的

不是 238 章内容，是这几样**方法**：

1. **「示例必须演示出它自己要讲的问题」**——`x=5` 演示不出 `&` 与 `and` 的差别，单 seed 的 KMeans 演示不出初始化差异
2. **「改一处要 grep 全库」**——同一个说法散在正文、陷阱表、小结、自测题里，只改一处就变成自相矛盾
3. **「能跑就别读」**——三轮阅读都没抓到的 `boxplot(labels=)` 改名、`StructuredOutputParser` 被删，跑一遍就现形
4. **「事实清单是防复发的」**——每条记录「正确答案 + 曾经的错法 + 能拦的正则」
