## 本轮的头号问题（值得写进手册）

1. **修一处留一处**：只改正文，陷阱表/小结/自测题没同步 → 同章三种说法并存。占本批发现的近四成。
2. **自己改出来的回归**：`File(...)` 说成必需、`tick_labels` 与 3.8.2 冲突、`PositionalEncoding` 只补成员没补类、`set_salary` 改签名没改函数体、checkpoint 打在源 RDD、Coze 收尾步骤没跟警告同步。
3. **过时 API**：`StructuredOutputParser`（LangChain 1.x 已移除）、`boxplot(labels=)`（3.9 改名）、`sc.makeRDD`（PySpark 从来没有）、`--driver-ui-port`（spark-submit 没有这个参数）、`memory search/delete`（Hermes 只有 add/replace/remove）。
4. **计数与编号**：五层 vs 六层、四张表 vs 五张、四步 vs 五步闭环、六步 vs 五步安装、八种状态 vs 六种、四档 vs 三档 BMI。
5. **结构缺陷**：同一文件两个 `@@h1`（后者覆盖整页标题）、重复 `@@summary`、知识点编号跳号。
