第 5 章 应用启动与测试 API

第 6 章 JWT 登录与认证鉴权

  • 目录里应该有：auth.py（/login + _make_token + get_current_user_id），config.py 里新增 JWT_SECRET、JWT_ALGORITHM、JWT_ACCESS_EXPIRE_SECONDS
  • 跑这条：curl -X POST http://127.0.0.1:8000/v1/auth/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"你的密码\"}"

  • 卡点：给 /login 也挂上 Depends(get_current_user_id) → 自己都登不进来；白名单接口绝不能挂鉴权

第 7 章 前端工程接入与联调
