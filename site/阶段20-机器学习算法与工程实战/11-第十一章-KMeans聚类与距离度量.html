第十一章　KMeans 聚类与距离度量：无监督的"物以类聚"

阶段 20 · 机器学习算法与工程实战　|　聚类算法　|　难度 ★★☆
这一章在解决什么问题

到目前为止，所有算法都需要"带标签的数据"（y 已知）——这叫监督学习。但现实中大量场景是：数据躺在那里，没人告诉它对错——比如给一批用户分群、给新闻自动分组、给图片找人脸。这就是无监督学习，而聚类是它的头号代表。

KMeans（K 均值）是聚类算法里最著名、最常用、最直觉的一个：给你一堆点，告诉它"分成 K 堆"，它自己把相似的聚在一起。名字拆开就懂：K = 分几堆（你定），Means = 每堆的中心是它的均值。

这一章学三件事：①KMeans 的完整流程（四步）；②它凭什么"聚得好"（距离度量 + 目标函数）；③K 怎么选（肘部法）。它是后面 KMeans 变体、密度聚类的地基。

上一章→本章→下一章 上一章结束监督学习的线性家族。本章转入无监督：理解聚类任务、KMeans 四步流程、欧氏/余弦距离、SSE 目标与肘部法选 K（讲义4 全部 10 页）。下一章讲 KMeans 的五个改良变体（KMedoids、二分 KMeans、KMeans++、elkan、Mini-Batch，讲义5），再下一章讲能聚"任意形状"的密度聚类（讲义6）。
1① 聚类的任务定义：无监督的"分堆"
要解决什么

聚类要解决什么问题？它和监督学习的本质区别是什么？

核心思路

聚类（Clustering）：把没有标签的样本，按照"相似度"自动分成 K 组。目标：簇内尽量相似（紧凑），簇间尽量不同（分离）。

  • 输入：只有 X，没有 y。
  • 输出：每个样本一个组号（0~K-1）——这个组号是"学出来的"，不是"标注好的"。

和监督学习的关键区别：

维度分类（监督）聚类（无监督）
训练数据X + y（有标签）只有 X
学到什么边界/模型分组/结构
典型用途预测新样本类别洞察数据内在结构

应用场景举例：用户画像分群（推荐策略不同）、商品聚类（同类定价）、图像分割（相似像素归一组）、异常检测（小簇=异常）。

认识聚类结果的价值：聚类产出"组号"，业务解释权在人——你最后还要给每组起个名字（"高价值用户""活跃但低转化"），这步叫"解读簇"。

坑在哪
现象原因 / 怎么办
拿聚类结果当"正确答案"聚类组号没有上帝标准，是否"好"取决于业务解释——这是无监督的本质
用分类准确率评估聚类没有 y 就没有准确率；聚类用自己的指标（SSE、轮廓系数）评估（本章+后文）
2② KMeans 的核心概念：中心点与平均
要解决什么

KMeans 的心智模型是什么？"K"和"Means"分别指什么？

核心思路

KMeans = K 个簇 + 每个簇的中心是"簇内所有点的均值"。

  • K：簇的个数，超参数（人定，靠肘部法/业务定）。
  • 质心/中心点（centroid）：每个簇的代表点，= 该簇所有样本坐标的平均：
中心_k = (1/|簇k|) · Σ_{x∈簇k} x
  • 每个样本属于"离它最近的质心"所在的簇。

直觉画面：先随便摆 K 个中心 → 样本认领最近的中心分为 K 组 → 每组重新算平均得到新中心 → 再认领……反复几轮，中心和分组互相"校准"，最终稳定。目标函数（SSE）被一步步压小。

"均值"二字道破本质：簇的形状趋向"球形"（各向同性），也是后续变体（KMedoids 用中位数）改进的出发点。

坑在哪
现象原因 / 怎么办
以为 KMeans 会自动发现 KK 必须人给；选错 K 全靠肘部法、业务知识或更多指标
忽略"初始中心"的影响初始点不同可能聚到不同局部最优；所以才有 KMeans++（下章）
3③ KMeans 四步流程：认领与重算的循环
要解决什么

算法到底怎么跑？把"摆中心-认领-重算"写成可执行的四步。

核心思路

标准 KMeans 流程（Lloyd 算法）：

  1. 初始化：随机选 K 个样本作为初始质心。
  2. 分配：每个样本归入"距离最近的质心"所在簇。
  3. 更新：对每个簇，用簇内样本的均值作为新质心。
  4. 重复 2~3，直到质心不再变化（或变化小于阈值、达到最大轮次）。
from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
kmeans.fit(X)
labels = kmeans.labels_      # 每个样本的簇号
centers = kmeans.cluster_centers_   # 质心坐标
  • labels_：样本到簇的映射。
  • cluster_centers_：K 个质心。
  • n_init：跑几轮不同初始值，取最优（防局部最优，sklearn 新版默认 10，老版默认 10→现改为自动）。

收敛性：每轮迭代，目标函数（SSE）单调不增，必终止——这是 KMeans 的数学保证。

坑在哪
现象原因 / 怎么办
忘记归一化就聚类KMeans 基于距离，量纲大的特征霸道主导；先 StandardScaler 再 fit
以为结果与初始中心无关不同初始值可能收敛到不同解；用 n_init>1 + 固定 random_state
4④ 距离度量：聚类的最底层逻辑
要解决什么

"距离最近"的"距离"到底怎么算？不同距离测度会得到完全不同的簇。

核心思路

常用三种距离：

  1. 欧氏距离（Euclidean）：最常用，两点直线距离：
d(x, y) = √(Σ_j (x_j - y_j)²)
  1. 余弦距离/相似度（Cosine）：只关注方向、忽略大小：
cos(x, y) = (x·y) / (|x|·|y|)，距离 = 1 - cos

常用于文本（词频向量方向代表话题）。

  1. 曼哈顿距离：各维度绝对差之和（城市街区式走路距离），对噪声相对鲁棒。

选型要点：连续数值特征、量纲已归一 → 欧氏；稀疏高维（文本/画像）→ 余弦。注意：特征提前做标准化后，余弦与欧氏的行为趋于一致（方向与大小都受控）。

坑在哪
现象原因 / 怎么办
文本聚类用欧氏文本向量长短差异巨大，方向才是语义；用余弦
欧氏和余弦混用不归一化先统一预处理口径（标准化），否则两种距离结果不可比
5⑤ 目标函数 SSE：聚得好不好有数可算
要解决什么

"簇内紧凑、簇间分离"太抽象。KMeans 优化目标写成数学是？

核心思路

SSE（误差平方和）/惯性（inertia）：所有样本到所属质心的距离平方和。

SSE = Σ_k Σ_{x∈簇k} |x - center_k|²
  • KMeans 的优化目标 = 最小化 SSE（每步分配与更新都在降 SSE）。
  • sklearn 用 kmeans.inertia_ 直接读出。
  • SSE 永远随 K 增大而下降（簇越多，每簇更紧）——所以不能用"SSE 最小"选 K，K=样本数时 SSE=0 但毫无意义。

另一评估视角：轮廓系数（Silhouette） 综合"簇内紧凑 + 簇间分离"，取值 [-1,1]，越接近 1 越好，用于给 K 打分（不随 K 单调漂移）——肘部法之外更严谨的选 K 工具。

坑在哪
现象原因 / 怎么办
用"SSE 最小"选 KSSE 随 K 单调降，比不出"相对最优"；要用膝盖点（肘部）或轮廓系数
聚类前不做量纲处理直接比较 SSE不同量纲下 SSE 数值无意义；先标准化再算
6⑥ 肘部法：K 怎么选（经验法则）
要解决什么

K 是超参数，怎么科学地定？最直观方法是看"SSE-K"曲线的膝盖。

核心思路

肘部法（Elbow Method）：

  1. 取 K=1,2,3,...,K_max，各跑一次 KMeans，记下每个 K 的 SSE。
  2. 画"K-横轴、SSE-纵轴"曲线。
  3. 曲线从"陡降"转为"平缓"的拐点（肘部）就是建议的 K。

原理：K 很小时再增加簇，SSE 下降极快（一个簇拆两个，内聚大涨）；过了真簇数，继续加簇收益递减（把本来就分开的点强行再拆）——曲线的"膝盖"反映真实结构层级。

import matplotlib.pyplot as plt
sse = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)
    sse.append(km.inertia_)
plt.plot(range(1, 11), sse, 'o-')
plt.xlabel("K"); plt.ylabel("SSE"); plt.show()

局限：真实数据往往"膝盖不明显"（曲线圆滑），肘部法是经验参考，还需结合业务含义定 K（比如"我要 3 个用户群做运营"）。

坑在哪
现象原因 / 怎么办
曲线没明显肘部就抓瞎数据本来就无清晰簇结构；这时回到业务/轮廓系数辅助判断
只看肘部法结果定 K 就交付结合业务目标与轮廓系数交叉验证，K 定错影响整条分析链
7⑦ 数据预处理与 KMeans 的"形状偏好"
要解决什么

KMeans 有哪些隐藏的"脾气"？数据不配合时会聚出什么怪样？

核心思路

KMeans 的三大脾气（理解它们避免被结果骗）：

  1. 吃归一化：距离算法，量纲敏感 → 先 StandardScaler。
  2. 偏好球形簇：用欧氏均值定义中心，天然假设各簇是"均匀圆球"；遇到elongated（长条形）、凹形、嵌套环状的簇，KMeans 会硬切成几段或把环形中间的人为切开——它是错的也"收敛得很自然"。这类数据要让位给密度聚类（第十三章 DBSCAN）。
  3. 对离群点敏感：均值被离群点拉动，质心偏移；可先用 KMedoids（中位数，下章）或预处理剔除。

识别手段：聚类后画散点图目检（不同簇用不同颜色），看簇边界是否符合直觉——可视化是聚类验收的必备动作。

坑在哪
现象原因 / 怎么办
环形/月牙形数据聚出来"很怪"还当正常KMeans 只吃球形；形状复杂请换密度聚类
离群点把簇中心拉飞均值=非鲁棒统计量；严重时换中位数版（KMedoids）或清洗
8⑧ 代码实战：二维数据的可视化聚类
要解决什么

理论完毕，动手：造一个"三团"模拟数据，跑 KMeans，把聚类结果画出来验收。

核心思路 
import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 三团高斯点（真实上是 3 簇）
np.random.seed(1)
X = np.vstack([np.random.randn(60,2) + [0,0],
               np.random.randn(60,2) + [5,0],
               np.random.randn(60,2) + [2,5]])
X = StandardScaler().fit_transform(X)

kmeans = KMeans(n_clusters=3, n_init=10, random_state=42).fit(X)

plt.scatter(X[:,0], X[:,1], c=kmeans.labels_, cmap='viridis')
plt.scatter(kmeans.cluster_centers_[:,0], kmeans.cluster_centers_[:,1],
            c='red', marker='x', s=200)          # 红色 X = 质心
plt.show()

验收三看：

  1. 三类样本被分成红/绿/紫三组，颜色内外干净。
  2. 红色 X 质心落在各簇"正中间"。
  3. 换不同 n_init/random_state 结果稳定。

可视化是聚类唯一"眼见为实"的验收方式——后续 DBSCAN、变体实战同样画图对比。

坑在哪
现象原因 / 怎么办
c=kmeans.labels_ 传错成预测值聚类用 labels_ 不是 predict；但 predict 也可对新样本给簇号（内部复用）
忘记 n_init 固定导致每次颜色编号乱跳设置 random_state 后簇编号稳定可复现；颜色不同不代表错了，是编号顺序问题
9⑨ KMeans 的局限总览：为下一章做铺垫
要解决什么

KMeans 这么好用，问题在哪？罗列它的五个软肋，下一章逐个给方案。

核心思路

KMeans 的五个已知软肋（及其解决方案预告）：

软肋表现解决（下章/后文）
初始中心敏感好初始收敛快，差初始卡局部最优KMeans++ 概率化初始化
聚类结果非全局最优SSE 只能保证收敛到局部二分 KMeans、多次 n_init
对离群点敏感均值被拉偏KMedoids 用中位数
距离计算太慢大数据每次算两两距离elkan 三角不等式剪枝
全量数据内存压力大样本全量迭代Mini-Batch KMeans 分片

这些变体不是"炫技"，每一个都对应 KMeans 的一个真实痛点——带着"痛点→方案"的对应关系去学下一章，效率翻倍。

坑在哪
现象原因 / 怎么办
以为换个变体就"万事大吉"每个方案有取舍（如 Mini-Batch 快但略不准）；按数据规模与精度需求选
数据形状非球形还坚持 KMeans 家族先认清数据形状：球形用 KMeans 系，任意形状用密度聚类

本章小结

KMeans 全貌：

问题答案
聚类是什么无监督分堆：簇内相似、簇间不同，只有 X 没有 y
K 和 Means 含义K=簇数（超参数），Means=质心取簇内均值
四步流程初始化中心 → 分配最近簇 → 均值更新中心 → 重复至稳定
距离度量欧氏（连续数值）、余弦（文本方向）、曼哈顿（街区）
优化目标SSE（惯性）：样本到质心距离平方和，逐轮不增
怎么选 K肘部法（SSE-K 曲线拐点）+ 业务 + 轮廓系数
三大脾气吃归一化、偏好球形、怕离群点
代码KMeans(n_clusters, n_init, random_state).fit(X)；画图验收
五个软肋初始敏感/局部最优/离群敏感/慢/内存大 → 下章逐个治

一句话记住本章：KMeans 把无标签数据按距离分成 K 堆，流程是"摆中心→认领最近的→均值更新中心→循环到稳定"，用 SSE 衡量紧凑度、肘部法定 K、先标准化再聚类；它只认"圆球形"簇、怕离群点、初始值影响大——这五个软肋正是下一章变体的由来。
