第四章　AutoDL 远程开发：SSH 免密与 IDE 接入

阶段 19 · 大模型开发工具平台　|　远程开发　|　难度 ★★★
这一章在解决什么问题

实例租好了，但问题接踵而至：每次 SSH 登录都要输密码，输错就进不去；训练脚本想用本地 PyCharm/VSCode 打开调试，但代码和文件都在云上，怎么"远程开发"？这一章解决三件事：① SSH 免密登录（一次配置终身方便）；② PyCharm 远程开发环境；③ VSCode Remote-SSH 远程开发。学完你就能像在本地一样写代码，实际上代码跑在云端 GPU 上。

本章是操作型章节，代码较少（1 条 ssh-keygen 命令 + 1 条 ssh 登录命令）。建议边看边操作。

上一章→本章→下一章 上一章解决了"租到一台带 GPU 的机器"。本章解决"怎么舒服地用这台机器"：先用 SSH 免密登录省掉输密码，再用 PyCharm/VSCode 把云端环境接进本地 IDE。下一章讲 AutoDL 的"学术加速"和"网盘"两个实用工具——加速解决 GitHub/HuggingFace 下载慢，网盘解决大文件跨机搬运。
1① 为什么要配 SSH 免密
要解决什么

每次 ssh root@xxx 都要手输密码，密码长还容易输错；更麻烦的是 IDE 远程连接、脚本自动拉取代码都要"非交互"方式登录——没有免密，这些全卡住。

核心思路

SSH 免密登录的原理是公钥认证：你本地保存私钥（身份凭证），把公钥放到服务器上。之后连接时，服务器用公钥验证，你本地用私钥应答，双方对上暗号就不用再输密码了。

本地电脑                    云端实例
┌──────────┐             ┌──────────┐
│ 私钥(id_rsa) │ ── 握手 ─→ │ 公钥(已登记) │
└──────────┘             └──────────┘
     对上 → 免密登录 ✓

好处：登录、scp 传文件、PyCharm/VSCode 远程、git 拉取都不用再输密码；也避免密码在脚本里明文保存的安全隐患。

坑在哪
现象原因 / 怎么办
以为免密=服务器不用密码服务器 root 密码照样要设置；免密只是登录方式之一，密码仍可用来兜底
私钥文件丢了私钥是唯一凭证，丢了重配；私钥不要发给任何人、不要上传到云盘
2② 生成 RSA 密钥对
要解决什么

免密的第一步是本地生成一对密钥，但 Linux/Mac 和 Windows 的命令平台不一样，老版本 Windows 甚至没有 ssh-keygen。

核心思路

用 ssh-keygen 生成 RSA 密钥对，一路回车即可（默认路径与空口令）：

# Linux/Mac：打开 Terminal 执行
ssh-keygen -t rsa

# Windows：打开 PowerShell 终端执行（命令相同）
ssh-keygen -t rsa

生成结果：在用户主目录的 .ssh 文件夹下出现两个文件——id_rsa（私钥，不要泄露）和 id_rsa.pub（公钥，可以公开）。

各平台生成路径：

  • Windows：C:\Users\{用户名}\.ssh\
  • Linux/Mac：/home/{用户名}/.ssh/

> 老版本 Windows 报错没有 ssh-keygen 命令：需要安装 Git Bash，然后用 Git Bash 终端执行上面的命令生成密钥对（Git 自带的 openssh 工具）。

坑在哪
现象原因 / 怎么办
Windows 提示"ssh-keygen 不是内部或外部命令"系统中没有 OpenSSH 客户端；安装 Git Bash 后用它的终端执行
生成时提示文件已存在说明之前生成过密钥；直接用已有的，或者先删再重新生成（会覆盖旧密钥）
私钥和公钥搞混带 .pub 后缀的是公钥（发出去）；不带后缀的是私钥（自己留，绝不外发）
3③ 把公钥登记到 AutoDL
要解决什么

密钥生成出来了，但服务器还不知道你的公钥，得把"打卡信息"登记到 AutoDL 后台。

核心思路
  1. 打开本地的 id_rsa.pub 文件，完整复制全部内容（以 ssh-rsa 开头的很长一串）。
  2. 进入 AutoDL 控制台，找到 SSH 公钥/密钥管理入口（通常在"账号设置"或"密钥管理"菜单）。
  3. 粘贴公钥并保存。

配置完，公钥就与你的账号绑定；之后创建的实例（或已有实例）都能用它免密登录。注意：修改公钥后通常对已有实例需要重装/同步一次或对新实例直接生效，不同版本平台略有差异，以实际为准。

检查项：保存后回到列表，能看到一条以 ssh-rsa 开头、带邮箱或注释的密钥记录，即配置成功。

坑在哪
现象原因 / 怎么办
只复制了部分公钥必须复制完整全部内容，少一个字符都验证失败；用编辑器全选复制
登记后依然要密码确认登记的是 id_rsa.pub（公钥）而不是私钥；确认连接的是同一账号下的实例
换电脑后免密失效新电脑要重新生成并登记公钥；或把原私钥复制到新电脑 .ssh 目录（注意安全）
4④ SSH 命令行登录详解
要解决什么

图形工具好用，但命令行 SSH 是基础能力：脚本、自动任务、临时连接都要用到它。需要把"连接命令长什么样、每个参数什么意思"彻底搞清楚。

核心思路

SSH 命令的基本格式（AutoDL 实例控制台会把现成命令给你，形如）：

ssh -p 12345 root@region-1.example.com

拆开看四个部分：

部分含义说明
ssh命令本身使用 SSH 协议连接远程主机
-p 12345端口参数指定连接端口（AutoDL 非默认 22 端口，必须带）
root用户名AutoDL 实例统一为 root
@region-1.example.com主机地址你的实例专属地址，每个实例不同

回车后首次连接会提示确认主机指纹（输入 yes），随后弹出密码输入窗口，输入实例密码即登录成功。连接成功后光标前出现 root@主机名 前缀，就可以在云端执行命令了。

注意：不同实例的端口和地址都不同，直接复制控制台给你的命令最保险；忘记密码去控制台重置。

坑在哪
现象原因 / 怎么办
命令回车后一直卡住实例可能未开机或网络不通；回控制台确认状态为"运行中"再连
弹出 host key 确认首次连接正常现象，输入 yes 回车继续
复制命令带了行尾特殊字符去掉多余空格/换行再粘贴；否则可能报"command not found"
5⑤ XShell 登录云实例
要解决什么

命令行 SSH 输入一长串命令，还有密码弹窗；Windows 用户习惯图形工具，希望有个好用的 SSH 客户端。

核心思路

XShell 是 Windows 下常用的 SSH 图形客户端。登录步骤：

  1. 打开 XShell → 新建会话（New Session）；
  2. 填 Host（实例的 SSH 地址）与 Port（实例 SSH 端口）；
  3. 用户填 root，连接；
  4. 首次连接会弹密码输入窗口，输入实例密码（或选择已配置的密钥登录）。

连接成功后就是熟悉的命令行界面，可以跑命令、装包、训练。XShell 好处：会话配置可保存、断开自动重连、界面比裸终端友好，适合长期管理多台实例。

如果是命令行方式，等价的连接命令是：ssh -p 端口号 root@实例地址，回车后按提示输入密码。

坑在哪
现象原因 / 怎么办
Host/Port 填错连不上实例控制台里有现成的 SSH 登录命令（含 Host、Port、User），直接复制拆分填进去
弹窗输入密码后仍失败确认是实例密码而不是账号密码；密码一般只在创建实例/重置时给出，忘了去控制台重置
连接超时实例可能已关机；先去控制台开机再连接
6⑥ PyCharm 配置远程 SSH 解释器
要解决什么

在本地写代码、到云端跑，来回同步文件很痛苦。PyCharm 支持把远程机器的 Python 解释器接进来：本地写代码，运行/调试时自动在云端执行，代码自动同步。

核心思路

PyCharm 配置远程开发的核心是远程解释器（Interpreter）：

  1. 打开 File → Settings，搜索 interpreter，进入 Python Interpreter 设置；
  2. 点击 Add Interpreter，选择 On SSH（远程 SSH）——注意：PyCharm 社区版没有该选项，需专业版（Pro）；
  3. 将实例 SSH 指令中的 Host、Port、Username 匹配填写（Username 一律 root，Host 和 Port 看自己实例的 SSH 指令）；
  4. 下一步：输入 SSH 的密码（或选择密钥）；
  5. 继续下一步，看到弹窗后选择 System Interpreter，配置远程解释器地址为 /root/miniconda3/bin/python（若在 miniconda 中建了虚拟环境，则路径为 /root/miniconda3/envs/{环境名}/bin/python）；
  6. 配置同步目录：远程路径设为实例数据盘子目录 /root/autodl-tmp/project/（不建议用默认的 /tmp 目录，重启会丢）；
  7. 点击创建，配置无误则完成远程开发环境。

之后本地写代码 → PyCharm 自动同步到云端 → 运行按钮在云端执行。这就是"本地编辑器 + 云端 GPU"的标准开发姿势。

坑在哪
现象原因 / 怎么办
找不到 "Add Interpreter → On SSH"社区版没有此功能；升级 PyCharm Professional 或改用下面的 VSCode 方案
运行时找不到 Python 文件代码没有自动同步；在 PyCharm 里对项目目录手动同步（Upload）到远程目录
用了 /tmp 目录，重启后代码没了同步目录必须用数据盘路径（/root/autodl-tmp/...），别用 /tmp
7⑦ VSCode 配置 Remote-SSH
要解决什么

不想为远程开发单独买 PyCharm 收费版，或者想用 VSCode 轻量编辑。VSCode 的 Remote-SSH 是免费方案，而且体验接近本地开发。

核心思路

VSCode 远程开发三步走：

  1. 本地安装 Remote-SSH 插件：打开 VSCode → 扩展市场搜索 Remote-SSH → 安装（已安装可跳过）；
  2. SSH 连接云实例：获取并复制实例的 SSH 登录信息（形如 ssh -p 12345 root@region-1.example.com），在 VSCode 左下角绿色远程按钮 → "Connect to Host" → 粘贴命令回车（注意命令末尾如有空格要删掉，否则可能无法登录）；
  3. 选择系统并输密码：回车后如弹出自定义 SSH config 文件的弹窗，直接回车即可；随后出现选择服务器系统的选项，选择 Linux；输入密码，等待 SSH 登录完成。

连接成功后，VSCode 左下角会显示远程地址，左侧文件树就是云端文件系统，打开的终端直接是云端 shell——本地编辑器，云端执行，全程免费。

贴心提示：VSCode 会自动安装服务器端组件，首次连接稍慢；后续重连就很快了。

坑在哪
现象原因 / 怎么办
粘贴 SSH 命令末尾有空格导致连不上删除命令末尾的空格再回车（官方提示的经典坑）
弹出服务器系统选择时选错必须选 Linux；选 Windows 会导致连接失败
连接成功但终端不在项目目录手动 cd /root/autodl-tmp/project/；或在 VSCode 设置里配置默认远程目录
插件装不上/服务器端组件下载失败网络受限时可开"学术加速"（下一章）再装，或换网络环境重试
8⑧ 远程开发环境联动：本地写、云端跑
要解决什么

学会了单独配置某个 IDE，但实际开发中"本地写代码、云端跑训练"的配合关系容易乱：file 同步到哪、依赖装在哪、看到的结果是哪个环境的，需要一次讲清。

核心思路

把远程开发理解成一条装配线，四个角色各司其职：

角色位置职责
代码编辑本地 IDE写代码、调试断点
远程解释器云实例执行代码、跑训练
同步目录云数据盘（/root/autodl-tmp/project/）本地↔云端代码对齐
依赖环境云端 miniconda 环境装包、版本隔离

正确的工作流：本地写代码 → 自动/手动同步到云端项目目录 → 运行按钮触发云端解释器在对应 conda 环境执行 → 日志/结果回传本地窗口显示。

三个容易乱的地方：

  1. 环境跟人走：激活哪个 conda 环境，代码就在哪个环境里跑，与 IDE 无关；运行前确认 (env名) 前缀；
  2. 同步以云端为准：训练用的永远是最新同步上去的代码，改完本地一定要同步再跑；
  3. 大文件不进仓库：数据集/模型放数据盘独立目录，代码目录只放脚本，避免同步超时。

检查项：本地改一个 print 并运行，能在输出看到改动，且云端文件树上对应文件已更新，即表示整条链路打通。

坑在哪
现象原因 / 怎么办
本地改了代码但云端跑的还是旧版忘记同步；PyCharm 手动 Upload，VSCode 看左下角"同步"状态或保存时自动同步
运行报错却本地无报错云端环境缺包；在云端终端 pip install 或 conda activate 正确环境后再跑
大文件让同步卡死把数据集/模型放到项目目录之外（/root/autodl-tmp/data），代码目录只同步脚本

本章小结

这一章把"租到手的 GPU 机器"变成了"本地一样的开发体验"：

问题答案
为什么要免密减少输密码，IDE/脚本/传文件都依赖免密登录
怎么生成密钥ssh-keygen -t rsa，一路回车；Windows 老版本用 Git Bash
公钥还是私钥.pub 是公钥发给服务器；不带后缀是私钥，绝不外传
公钥登记到哪AutoDL 控制台「SSH 公钥」菜单，粘贴完整公钥内容
命令行登录ssh -p 端口 root@实例地址，回车输密码（控制台有现成命令）
图形客户端XShell 新建会话填 Host/Port/user，输入密码即可
PyCharm 远程File→Settings→Interpreter→Add→On SSH，配解释器与同步目录（社区版无此功能）
VSCode 远程装 Remote-SSH，粘贴 ssh 命令，选 Linux，输密码即可
联动原则本地写→同步云端→云端环境执行；运行前确认环境与同步完成

一句话记住本章：SSH 免密一句话（ssh-keygen 生成、公钥登记 AutoDL）；PyCharm 要专业版走 On SSH，VSCode 免费版装 Remote-SSH 粘贴 ssh 命令选 Linux；记住"本地写、云端跑、数据放 autodl-tmp"。
