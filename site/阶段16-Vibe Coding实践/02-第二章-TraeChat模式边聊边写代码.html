第二章　Trae Chat 模式：边聊边写代码

阶段 16 · Vibe Coding 实践　|　工具实操　|　难度 ★☆☆
这一章在解决什么问题

你装好了 Trae，登录了账号，然后呢？ 面对的是一块空荡荡的编辑器——到底怎么让 AI 帮你干活？最直接的入口就是 Chat 模式：像和同事聊天一样，在侧边对话框里说"帮我把这段代码改成递归写法"、"看看这个报错是什么意思"，AI 的回答就出现在你面前。

Chat 模式是 Trae 的三种工作面（Chat、Builder、上下文协作）里最常用、最容易上手的一种。 它解决的核心问题是"在写代码的过程中随时问、随时改、随时用"——不需要跳出编辑器去查文档、去搜索引擎、去复制粘贴代码。

学完这一章，你能回答：怎么打开 Chat 模式、怎么选模型、AI 生成的代码块怎么处理、AI 给的 Shell 命令怎么运行、项目改砸了怎么回退、历史对话怎么管理。这一章全是"马上能用"的操作，学完你就能和 Trae 进行第一轮真实协作。

这一章在整个知识库里的位置 上一章：你完成了 Trae 安装与登录，知道了"Trae 是 AI 深度集成的 IDE"。 本章 ← 你在这里：掌握 Chat 模式——Trae AI 协作的第一块工作面 下一章：Builder 模式——不止问答，让 AI 自动读项目、建文件、跑命令，从 0 到 1 完成项目 再往后：上下文与 Rules → 模型切换与自定义模型 → MCP 旅行助手实战 → Cursor → Codex 阶段终点：熟练用三款 AI 编程工具的交互模式完成实际开发
学习提示

Chat 模式的操作点很多，但别被吓到——记住一条主线：打开 → 提问/选模型 → 处理 AI 的产出（代码块/命令）→ 不满意就回退或删对话。把这条主线走通，细节操作（按钮位置）遇到时随手查就行。

1① 打开 Chat 模式：两种路径
要解决什么

Chat 模式怎么进？装完 Trae 后默认就在 Chat 模式，但如果你切到了别的界面，需要知道怎么回来。

核心思路

进入 Trae 后一般默认进入 Chat 模式。若不在，用以下两种方式打开：

  1. 快捷键：macOS 按 Command + U；Windows 按 Ctrl + U——打开侧边对话框；
  2. 手动点击：在侧边对话框的左上角，点击 Chat 切换到聊天面板。

之后与 AI 的问答都发生在这个侧边对话框里：你输入自然语言描述需求，AI 返回文字说明、代码块或命令。

坑在哪
现象原因 / 怎么办
按了 Ctrl+U 没反应确认焦点在 Trae 窗口内；部分输入法会吞快捷键，切到英文输入再试
找不到"Chat"按钮侧边框左上角有两个 Tab：Chat 和 Builder；点 Chat 即切回问答模式
2② 选择模型：默认豆包，可切 DeepSeek
要解决什么

AI 回答的质量和风格跟模型强相关。Chat 模式用哪个模型？能不能换？

核心思路

Chat 模式默认使用 Doubao-1.5-pro（豆包） 模型。你可以点击模型名称，在列表里切换：

  • Doubao-1.5-pro：默认模型，字节自家，中文场景表现稳定；
  • DeepSeek-Reasoner (R1)：推理型模型，适合复杂逻辑、数学、代码推理；
  • DeepSeek-Chat (V3)：通用对话模型，响应快。

不同模型能力侧重不同，通过对话输入框右下角的模型名称即可切换。写普通业务代码用默认豆包没问题；遇到需要"想清楚再答"的难题（算法、架构选型）可以临时切到 R1。

坑在哪
现象原因 / 怎么办
切换模型后上下文丢了切换模型不会清空当前对话，但不同模型对上下文的利用方式有差异，复杂需求建议主用同一模型
找不到模型列表列表入口在输入框右下角的模型名称处，点击即弹出
3③ 处理 AI 生成的代码块：复制 / 插入 / 存新文件 / 应用
要解决什么

AI 回复里最常见的是代码块。怎么把它"搬运"进你的项目？Trae 提供了四种操作，分别对应不同场景。

核心思路

AI 给出的代码块，右上角有操作按钮，按需选用：

编号操作场景
1复制复制代码块中的全部内容，粘贴到任意位置（其他软件、聊天记录等）
2插入到光标处在编辑器内的文件中点击目标区域，把代码插入到光标处——改现有文件最常用
3添加到新文件新建一个文件，把代码添加进去——AI 生成整个新模块时最方便
4应用若为代码变更，将变更后的代码应用至相应文件（注意：不支持应用和当前工作空间项目无关的代码）

前三种是"搬运"，第四种是"替换"——尤其是"应用"，它直接改文件，属于要留神的操作。

坑在哪
现象原因 / 怎么办
点"应用"报错"和当前工作空间项目无关"AI 生成的代码不属于当前项目；先确认打开了正确项目，或改用"添加到新文件/插入到光标处"
插错位置插入到光标处是"光标在哪插哪"；先点好目标位置再操作，误插可用 Ctrl+Z 撤销
直接复制到外部工具后代码缩进乱了部分软件粘贴会吃空格；贴回编辑器后全选重排（Trae 支持格式化）
4④ 处理 AI 生成的命令：复制 / 加终端 / 运行
要解决什么

AI 有时不只给代码，还会给出 Shell 命令（装依赖、跑测试、启动服务）。Chat 模式对命令也做了贴心处理。

核心思路

Chat 模式下，AI 会根据你的需求提供可一键运行的 Shell 命令，命令卡片上有三个操作：

编号操作说明
1复制复制该命令，粘贴到任意终端
2添加到终端将命令添加至尚未被占用的终端
3运行直接在未被占用的终端中运行该命令

也就是说，AI 给的命令可以在编辑器里直接"一键跑"，不用你手动复制到外部终端。

坑在哪
现象原因 / 怎么办
点"运行"没反应或终端被占用所有终端都被占用了；关掉一个闲置终端，或用"添加到终端"排队
命令可能对系统有影响（如删除文件）AI 给的命令请你先读一眼再运行；不确定的命令先复制去查看，不要盲点"运行"
Windows 与 macOS 命令不通用确认命令跟你的操作系统匹配（如 pip 与 pip3、路径分隔符），不符则让 AI 重出
5⑤ 回退版本：Chat 模式也能撤回
要解决什么

AI 帮你改了一段代码，但改完发现还不如原来。怎么"回到对话发生前"？——这就是 Chat 模式的回退版本功能。

核心思路

你可以将项目回退至指定会话轮次发起前的版本。操作步骤：

  1. 找到目标对话气泡；
  2. 点击左侧的 回退 按钮；
  3. 对话框中展示本次回退会影响的文件；
  4. 点击文件名可打开文件查看将发生的变更；
  5. 确认影响范围符合预期后，点击 确定，AI 助手开始回退项目。

三条硬性限制（务必记住）：

  • 回退操作不可撤销；
  • 仅支持在最近活跃的 Builder 窗口中回退版本；
  • 仅支持回退至最近 10 轮会话内的版本。
坑在哪
现象原因 / 怎么办
回退后发现回不去了回退不可撤销！回退前一定点文件名确认变更内容，尤其在改动较多时
提示"仅支持最近活跃的 Builder 窗口"回退功能绑定 Builder 模式窗口；长期未用的窗口不算活跃，先进 Builder 再操作
想回退 10 轮之前的版本超出回退范围；靠 Git 版本管理兜底（阶段 16 Codex 章节会讲 Git）
6⑥ 管理历史对话：查看、跳转、删除
要解决什么

对话一多，之前的问答找不到了。Chat 模式提供历史记录管理，让对话可回溯、可清理。

核心思路

点击 Chat 窗口右上角的历史会话按钮后，左侧会显示历史记录窗口，展示 Chat 模式和 Builder 模式的所有对话记录。

  • 查看历史：点击某条对话，会跳转至该对话的位置，继续浏览或追问；
  • 删除对话：鼠标悬浮至某条对话，点击右侧的删除图标即可删除。

⚠️ 对话记录删除后无法恢复。

坑在哪
现象原因 / 怎么办
手滑删了重要对话删除不可恢复！重要的方案对话建议尽早复制备份到本地笔记
找不到之前的对话先确认在"历史会话"视图里，且按 Chat/Builder 分类找；搜索功能在部分版本的热键是 Ctrl+G（Codex 相同）
7⑦ 一个完整场景演练：从提问到落地
要解决什么

把第 ①-⑥ 点的知识串成一个真实流程，让你知道"一次 Chat 协作"长什么样。

核心思路

假设你想在项目里写一个"判断闰年"的函数，完整流程如下：

1. 打开 Chat（Ctrl+U），输入：
   "帮我写一个 Python 函数，输入年份返回是否闰年，要带注释"
2. AI 返回代码块 + 说明
3. 代码块操作：点"添加到新文件"，命名为 leap.py
4. 继续追问："加一个命令行入口，能直接 python leap.py 2026 运行"
5. AI 返回新代码；点"插入到光标处"补进文件
6. 运行测试：按提示的命令"python leap.py 2026"点"运行"
7. 验证输出；不满意就让 AI 改，满意则收工
8. 若改坏了：找到对应对话气泡点"回退"，确认变更后确定

这就是 Vibe Coding 的日常节奏：问 → 拿到代码/命令 → 选一种方式落地 → 验证/追问 → 必要时回退。

坑在哪
现象原因 / 怎么办
一次只问一步，来回十几轮尽量把需求一次说全（函数+入口+注释+输入校验），减少轮次
AI 答非所问补充上下文（第 3 章讲 # 引用），或换个更清晰的问法，别硬拗
8⑧ 对话素材补充：把代码和终端输出"投喂"给 AI
要解决什么

对话里想"让 AI 看某段代码/某条命令的输出"，除了手动复制粘贴，有没有更快的方式？

核心思路

Trae 提供两条"把现场素材带进对话"的快捷路径（讲义"添加到对话"功能）：

路径一：编辑器里的代码进对话

  1. 选中代码；
  2. 点击悬浮菜单中的 添加到对话 按钮；
  3. 选中的内容作为上下文被添加至侧边对话框，AI 基于它回答。

路径二：终端输出进对话

  1. 在终端中，点击输出内容片段；
  2. 点击内容片段区域右上角的 添加到对话 按钮；
  3. 命令输出被添加至侧边对话框。

与第 04 章的区别：04 章讲的是输入框里用 # 引用 选文件；本技巧是"选中即投喂"的无框路径——两条路都能把上下文喂给 AI，按操作习惯选。

坑在哪
现象原因 / 怎么办
选中代码后没出现悬浮菜单确认选中了完整代码块；部分版本需要鼠标在选区停留触发
终端输出太长塞爆对话先筛选关键片段再"添加到对话"，别整屏投喂
和 # 引用混着用把上下文撑爆两种方式都占用上下文；够用即可，别重复投喂同一段内容

本章小结

这一章你掌握了 Trae 最常用的 AI 协作入口——Chat 模式：

拿到了什么为什么要紧
打开方式：快捷键 Ctrl+U / Command+U，或点 Chat Tab随时把 AI 叫到面前
模型选择：默认 Doubao-1.5-pro，可切 DeepSeek R1/V3不同任务选不同强度的模型
代码块四操作：复制 / 插入光标处 / 添加到新文件 / 应用把 AI 产出落地的四种姿势，场景不同选法不同
命令三操作：复制 / 添加到终端 / 运行AI 给的命令一键执行，但要先读再跑
回退版本：指定对话轮次发起前，不可撤销、限活跃 Builder 窗口、限 10 轮内改错了有后悔药，但药量有限
历史对话：查看、跳转、删除（删除不可恢复）对话可管理、可清理

一句话记住本章：Chat 模式就是你在 Trae 里的 AI 问答台——打开它、说需求、处理代码块和命令、不满意就回退；下一步，让 AI 自己动手干活的 Builder 模式来了。
