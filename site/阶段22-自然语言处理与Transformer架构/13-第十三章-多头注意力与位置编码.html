第十三章　多头注意力与位置编码

阶段 22 · 自然语言处理与Transformer架构　|　多头注意力/位置编码　|　难度 ★★★
这一章在解决什么问题

单头自注意力只能学到"一种关系视角"，而句子里每个词同时承担多种角色：既可能是主语，又和另一个词构成修饰关系。多头注意力让多个注意力头并行、各管一个视角，再把结果拼接起来。与此同时，自注意力天生"不认顺序"，位置编码给每个词贴上先后坐标。这两块加上 FFN、残差与层归一化，Transformer 单层的零件就齐了。

上一章→本章→下一章 上一章学会了自注意力的四步计算。本章给它装上两个组件：多头注意力（多视角并行）与位置编码（补顺序），同时补齐 FFN、残差连接和层归一化三个工程件。下一章把这些零件组装成完整的 Transformer 编码器-解码器，并跑一遍机器翻译实战。
1① 为什么需要多头：一个注意力头不够用
要解决什么

词和词的关系五花八门，单个自注意力头能全照顾到吗？

核心思路

单头自注意力把"所有语义关系"挤进同一组权重矩阵，会出现平均化问题——既想抓主谓关系，又想抓指代关系、修饰关系，一个头忙不过来。

多头注意力（Multi-Head Attention）：使用多组独立的 Q/K/V 权重矩阵并行计算，每组（每个头）关注一种关系视角：

  • 头 1 学"主谓关系"（"我"-"爱"）
  • 头 2 学"指代关系"（"它"-"小猫"）
  • 头 3 学"修饰关系"（"美丽"-"花园"）

最后把各头结果拼接并线性变换融合。这让模型"一只眼睛看多种关系"，表达能力成倍提升。

坑在哪
现象原因 / 怎么办
以为多头=多算几遍没区别每个头自带独立参数、训练后各自分工，拼接融合后表达力远超单头
头之间共享参数头独立是前提，共享参数等于变回单头
2② 多头注意力的计算公式与流程
要解决什么

多头注意力的标准数学表达和实现流程是什么？

核心思路

公式（h = 头数，每个头维度 d_k = d_model / h）：

MultiHead(Q, K, V) = Concat(head_1, ..., head_h) · W_O
head_i = Attention(Q·W_Q^i, K·W_K^i, V·W_V^i)

流程拆解：

  1. 拆分：把 d_model 维的 Q/K/V 线性投影成 h 组，每组 d_k 维（降维后再算注意力）。
  2. 并行计算：h 个注意力头各自独立执行缩放点积注意力。
  3. 拼接：把 h 个头的输出沿特征维拼接，得到 d_model 维。
  4. 输出投影：乘 W_O 融合（可以理解为"把各视角结果汇总成最终表示"）。

典型配置：d_model=512，h=8，每头 d_k=64——"8 头 64 维拼接成 512 维"说的就是这一步。

坑在哪
现象原因 / 怎么办
拼接后忘记乘 W_O没有输出投影，各头结果只是简单堆叠，缺少融合
每头维度算错每头 d_k = d_model/h，接回时要与 d_model 对齐，写代码注意 reshape 顺序
3③ "8 头 64 维拼接 512"到底在说什么
要解决什么

"d_model=512、h=8、d_k=64"这套数字是怎么配合的？

核心思路

以一层的完整数据流看（batch，seq 长度略去）：

输入 x:        [512]           ← 每个词 512 维
拆成 8 个头:   [64]×8          ← 各投到 64 维
每个头自注意力: [64]            ← 8 个 [64]
拼接:          [512]           ← 8×64=512
输出投影 W_O:   [512]           ← 仍是 512，和输入同维度

关键设计：

  • d_k = d_model / h 保证拼回原维度（512/8=64），输出维度稳定。
  • 每头只需 64 维，"轻量头"并行 8 个，计算量与单头 512 维几乎相同，但视角多 8 倍。
  • 维度不变 → 方便堆叠多层、残差直连。

这套"分割-并行-拼接-投影"的流水就是多头注意力的工程骨架。

坑在哪
现象原因 / 怎么办
以为 8 个头输出都是 512 维每头是 64 维，拼起来才 512；理解"分割"是 512 拆 8 份
换 h 时忘记同步 d_kh 变了 d_model/h 也变，但拼接后维度必须仍等于 d_model
4④ 位置编码：给自注意力装上"顺序感"
要解决什么

"我爱学习"和"学习爱我"的词一样、顺序不同，自注意力怎么区分？

核心思路

自注意力对位置不敏感：它不知道"我"在"爱"前面。解决：位置编码（Positional Encoding, PE）——给每个位置一个唯一向量，加到词向量上：

输入 = 词嵌入 + 位置编码

Transformer 原文用的是三角函数编码：

PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

特点：

  • 每个位置独有、"距离感"由 sin/cos 频率天然体现（相邻位置编码相近）。
  • 可外推到更长序列（不需要在词表里"学"新位置）。
  • 与词向量同维度相加，零额外参数。

现在"我"与"爱"即使词义相近，携带的坐标也不同，注意力就能区分顺序。

坑在哪

把 pos 和 i 搞混pos 是词在句中的位置，2i/2i+1 是编码内部维度下标（奇偶交替 sin/cos）
5⑤ 词向量 + 位置向量：信息怎么共存
要解决什么

把位置编码直接加到词向量上，语义信息会不会被"覆盖"？

核心思路

相加而不是拼接，原理上成立：

  • 词向量与位置编码维度相同，各自占据不同"方向/子空间"。
  • 语义主要由词向量的方向表达，位置由编码的坐标模式表达；加权相加后，模型通过线性层可以解耦二者（线性可分）。
  • 实践中这是原文默认做法，训练稳定且省参数。

直觉类比：把"这是谁"（词义）和"站在哪"（位置）写在同一张纸条的不同区域——读的时候各取所需。

坑在哪
现象原因 / 怎么办
担心相加会混掉信息高维空间中方向和子空间可分，相加是原文验证过的做法，别改成拼接自行加复杂度
忘记位置编码也要参与梯度PE 固定公式不参与训练，但它乘上词向量一起前向传播，反向传播正常流动
6⑥ 前馈网络 FFN：逐位置的非线性加工
要解决什么

注意力层之后，为什么还要一个全连接网络？

核心思路

注意力输出是"各词关系的加权融合"，但只是线性组合。为了让每个位置的表示具备非线性表达能力，Transformer 每层末尾接一个前馈网络（Feed-Forward Network, FFN）：

FFN(x) = max(0, x·W1 + b1) · W2 + b2
（ReLU 激活的 2 层全连接，中间维度放大 4 倍如 512→2048→512）

要点：

  • 逐位置独立：对每个词分别做同样的变换（不跨词交互）。
  • 两步分工：先线性升维 + ReLU 非线性，再线性降维回来。
  • 位置共享同一套权重（卷积式共享），参数规模来自这里。

整个单层流程：自注意力 → 残差 → 层归一化 → FFN → 残差 → 层归一化。

坑在哪
现象原因 / 怎么办
以为 FFN 做了跨词信息交换FFN 逐位置独立，跨词交换靠注意力；FFN 负责"加工"不负责"通信"
中间维度写错一般中间层 = 4×d_model，不是 2×，写小表达能力打折
7⑦ 残差连接与层归一化：训练的"安全带"
要解决什么

Transformer 堆十几层，梯度消失、训练不稳怎么解决？

核心思路

两大工程件：

1. 残差连接（Residual）：让输出绕过当前子层直接累加：

x = x + Attention(x)
x = x + FFN(x)
  • 梯度可以"抄近道"穿过深层，缓解梯度消失。
  • 深层模型也能保底"至少不比浅层差"（恒等路径兜底）。

2. 层归一化（LayerNorm）：对每个样本的每一层输出，按特征维归一化（均值 0、方差 1，再学缩放/偏移参数）：

LayerNorm(h) = γ·((h - μ)/√(σ²+ε)) + β
  • 让数值稳定在温和区间，训练更快更稳。
  • 与 BatchNorm 的区别：对"每个位置的向量"归一，不依赖 batch 内其他样本，适合 NLP 变长序列。

标准顺序（Post-LN 或 Pre-LN）：残差前/后接归一化两种流派，用来稳定深层堆叠。

坑在哪
现象原因 / 怎么办
加了残差就忘归一化两者配合才稳：残差保梯度通路，归一化保数值尺度
把 LayerNorm 与 BatchNorm 混用NLP 序列场景默认 LayerNorm（逐位置独立），BatchNorm 依赖 batch 统计、变长序列下不稳定
8⑧ 组装：Transformer 编码器单层长什么样
要解决什么

把多头注意力、位置编码、FFN、残差、层归一化拼起来，单层结构图是什么？

核心思路

Transformer 编码器单层 = 两大子层：

输入: 词嵌入 + 位置编码
  ↓
[子层1] 多头自注意力
    x = x + MultiHead(x)      ← 残差
    x = LayerNorm(x)          ← 归一化
  ↓
[子层2] 前馈网络 FFN
    x = x + FFN(x)            ← 残差
    x = LayerNorm(x)          ← 归一化
输出: 编码器表示

要点回顾（层内各零件）：

  • 多头注意力：多视角关系建模（8 头 × 64 维 → 512）。
  • 位置编码：让注意力知道顺序。
  • FFN：逐位置非线性加工。
  • 残差 + LayerNorm：梯度通路与数值稳定。

整机 = 该层堆叠 N 次（如 6 层），配上解码器（含掩码多头注意力 + 交叉注意力），就是完整的 Transformer。下一章组装整机并实战翻译。

坑在哪
现象原因 / 怎么办
把"层"和"头"混为一谈头是注意力内部的并行通道，层是堆叠的深度；6 层 × 8 头是常见配置
子层顺序记乱标准顺序：残差(+子层) → 归一化（不同实现有 Pre/Post 差异，但"子层带入、残差相连、归一化收口"的骨架一致）

本章小结

本章补齐 Transformer 单层所有零件：

零件作用
多头注意力h 组 Q/K/V 并行，各自学一种关系视角，拼接融合
8头×64维d_model=512 拆 8 份，拼回 512，轻量并行
位置编码sin/cos 固定公式，给每个词加"顺序坐标"
FFN逐位置 4 倍宽非线性加工
残差连接保梯度通路，深层堆叠不退化
层归一化数值稳定，训练更稳更快
单层流程注意力→残差→LN→FFN→残差→LN
