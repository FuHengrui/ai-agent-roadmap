第十五章　ELMo动态词向量

阶段 22 · 自然语言处理与Transformer架构　|　预训练与动态词向量　|　难度 ★★★
这一章在解决什么问题

Word2Vec 生成的词向量是"静态"的：无论语境如何，"bank"永远只有一个向量，可它既可能是"河岸"也可能是"银行"。ELMo（Embeddings from Language Models） 第一次给出"动态词向量"方案：让同一个词的表示随上下文实时变化——核心是用一个双向语言模型把每个词编码成上下文的函数。这是 NLP 从"词向量"走向"预训练"的转折点。

上一章→本章→下一章 上一章训好了 Transformer 整机。本章回归"表示"本身：ELMo 用双向 LSTM 语言模型产出上下文相关的动态词向量。下一章 BERT 把"预训练+微调"模式发扬光大，GPT 侧则走"生成式"路线——三条线共同开启预训练大模型时代。
1① 静态词向量的天花板
要解决什么

Word2Vec 的词向量在新语境下出了什么问题？

核心思路

Word2Vec 训练好后，每个词有一个固定向量，使用时直接查表：

  • "去银行取钱" → bank = 商业机构义。
  • "在河岸散步" → 同一个向量！语境没参与。

问题总结（静态词向量的三大硬伤）：

  1. 一词多义无法区分："苹果"是水果还是公司，看语境才知道。
  2. 语境敏感缺失："好的"在不同句子里情感强度不同，向量却一样。
  3. 下游任务要自己重训：静态向量无法获取词在具体句子中的临时语义。

解法方向：让词向量在"读到句子"之后才生成——表示 = 词本身 + 它所在的上下文。

坑在哪
现象原因 / 怎么办
以为 Word2Vec 完全没有上下文信息它有"词共现"统计信息，但那是语料库级的静态规律，不是句子级动态语境
期望改 Word2Vec 能解决静态训练目标（预测邻居词）产不出动态表示，必须换"语言模型"式目标
2② ELMo 的核心思想：用语言模型做词向量
要解决什么

"动态"到底怎么实现？谁来提供上下文信息？

核心思路

ELMo 的回答：用一个语言模型（Language Model, LM）来产出词向量。语言模型天生"精于预测下一个词"，这意味着它被迫理解上下文：

  • 前向 LM：给定前文预测下一个词 → 学到"前文"信息。
  • 后向 LM：给定后文预测上一个词 → 学到"后文"信息。
  • 双向结合：每个词同时吃到"它之前"和"它之后"的信息。

ELMo 结构 = 双向 LSTM 语言模型（前向/后向各一组 LSTM 层）：

输入词嵌入 → 前向LSTM↑(h1^f..hn^f) + 后向LSTM↓(hn^b..h1^b)

每个词在第 k 层得到两个方向表示，ELMo 输出由各层双向表示加权组合。词义由"预训练时学会的语言规律"按当前句子即时计算——这就是"动态"。

坑在哪
现象原因 / 怎么办
以为 ELMo 是"双向 LSTM 直接拼"是前/后向两个语言模型各自训练后拼接，不是单一双向编码器
把"动态"误解成"每次都要重新训练"模型是预训练好的，推理时前向一次即可得到当前语境的动态表示
3③ ELMo 的层次表示：浅层管语法，深层管语义
要解决什么

ELMo 有多层 LSTM 表示，为什么不用"最后一层"，要加权组合？

核心思路

ELMo 的关键洞察：不同层的表示内涵不同：

  • 底层（接近词嵌入）：偏句法/词法（词性、形态）。
  • 高层（接近输出）：偏语义/上下文（一词多义、指代）。

所以 ELMo 把各层双向表示加权求和作为最终词向量：

ELMo_t = γ · Σ_L s_L · h_t^L
（γ 是整体缩放，s_L 是各层学出的权重，L 为层序号）

好处：下游任务可以自己调节学哪一层更多——句法任务多用低层，语义任务多用高层。这不是"挑一层"，而是"按需混合"，比只用最后一层更灵活。

坑在哪
现象原因 / 怎么办
只用最后一层层权重 s_L 是可学习的，任务会自动挑层；手动只用某层等于扔掉这种灵活性
忘记层权重是学出来的s_L 在微调下游时自适应更新，不是人工设定
4④ ELMo 的用法：特征式迁移
要解决什么

预训练好的 ELMo 如何"接"到下游任务里？

核心思路

ELMo 走的是特征拼接（Feature-based）路线：

下游任务输入 = [词嵌入 ; ELMo表示]
例如: 情感分类
  "这部电影真好看" → 每个词: [Glove向量 ; ELMo向量]
  → 双向LSTM/自注意力 → 分类器

要点：

  • ELMo 参数在训练下游任务时可以冻结（或微调）。
  • 下游模型只需把 ELMo 输出当额外特征接入，无需修改 ELMo 内部。
  • 对比：BERT 后走微调（Fine-tuning）路线——整个预训练模型都参与更新。

特征式 vs 微调式是两种迁移范式：ELMo 开创前者，BERT 把后者推到主流。

坑在哪
现象原因 / 怎么办
把 ELMo 的用法套到 BERT 上BERT 主流用法是微调（全量更新）；ELMo 是特征拼接（可冻结）。方法本身分属两条路线
忘记对齐序列长度ELMo 输出是每一步向量，与词的位置一一对应，拼入前要按 token 对齐
5⑤ 双向语言模型的训练目标
要解决什么

ELMo 被训练来"预测什么"，才能学到动态表示？

核心思路

ELMo 目标 = 前向 + 后向两个语言模型的对数似然之和：

前向: log P(t1..tn) = Σ log P(t_k | t_1..t_{k-1})   # 见上文预测下文
后向: log P(t1..tn) = Σ log P(t_k | t_{k+1}..t_n)   # 见下文预测上文

训练数据就是大量无标注文本（自监督）：语料库天然提供"前文→后文"的监督信号，无需人工标注。模型被迫理解词语搭配、句法、指代等语言规律，这些规律最终凝结在每一层的表示里。

自监督 + 大规模语料 = 预训练的核心配方，ELMo 是最早吃螃蟹的模型之一。

坑在哪
现象原因 / 怎么办
以为训练要人工标注语言模型是自监督任务，数据自动构造，这也是预训练能上大语料的原因
前向后向目标混在一起两个方向分别算各自的似然，最后相加；不是"同一个模型双向跑"
6⑥ ELMo vs Word2Vec：本质差异
要解决什么

ELMo 相对 Word2Vec，到底"新"在哪里？

核心思路
维度Word2VecELMo
表示类型静态（查表即得）动态（按句子实时算）
一词多义无法区分随语境区分
训练目标预测邻居词（词级别）语言模型（句子级）
结构浅层（单隐层）深层双向 LSTM
迁移方式查表特征多层特征拼接
上下文窗口内共现全句（前后向）

本质区别一句话：Word2Vec 学的是"词自己长什么样"，ELMo 学的是"词在句子中会变成什么样"。后者的表示从"词典"变成了"函数"。

坑在哪
现象原因 / 怎么办
把两者归为一类静态/动态是两代范式，先有 Word2Vec 后有 ELMo，ELMo 就是来补前者的死穴
觉得 ELMo 只是"加了 LSTM"关键是训练目标从词级别升到句子级，结构升级只是手段
7⑦ ELMo 的局限：为什么它不是终点
要解决什么

ELMo 已经动态了，还有什么不足？

核心思路

ELMo 三大局限（为 BERT 铺垫）：

  1. 双向是"拼接"不是"融合"：前向/后向各跑各的，最终拼接——词没同时看到完整双向上下文。BERT 的 Masked LM 才是"真双向"。
  2. LSTM 顺序计算：处理慢、长距离仍有衰减（RNN 的老问题）。
  3. 特征式迁移：下游任务要用额外结构承接 ELMo 特征，改造成本高于"直接微调"。

正是这些缺口，促使 BERT（双向深度 Transformer + 微调）在一年后全面超越 ELMo。

坑在哪
现象原因 / 怎么办
以为 ELMo 已经双向融合ELMo 前/后向是独立的两个 LM，没有在词级别融合双向上下文；BERT 的掩码语言模型才是真双向
高估了 LSTM 的并行能力LSTM 顺序依赖，无法像 Transformer 那样全并行
8⑧ ELMo 的历史地位：预训练时代的分水岭
要解决什么

ELMo 在 NLP 发展史中到底意味着什么？

核心思路

ELMo（2018，AllenAI）是预训练范式的发令枪：

  • 之前：谁都要从零训练模型，词向量只是"冷启动加速器"。
  • ELMo 之后："在大语料预训练 + 在下游小任务迁移"成为标准配方。

它的直接遗产：

  1. 证明"上下文相关表示"有效 → 催生 BERT/GPT 系列。
  2. 确立自监督预训练目标（语言模型）为核心训练方式。
  3. 提出"层表示按需加权"思想 → 后来的多层模型（GPT-2/3、BERT）都用这思路读取深层表示。

理解 ELMo，就理解了为什么后来"预训练-微调"成为 NLP 的绝对主流。

坑在哪
现象原因 / 怎么办
认为 ELMo 已被淘汰就没价值它的思想（动态表示、预训练、层融合）全部延续到现代模型，是必学的基础课
把 ELMo 归为"Transformer 类"它是 LSTM 架构；用它理解"表示范式的转变"，Transformer 属于下一波架构升级
