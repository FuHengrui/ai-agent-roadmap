第十七章　GPT生成式模型

阶段 22 · 自然语言处理与Transformer架构　|　GPT与生成式AI　|　难度 ★★★★
这一章在解决什么问题

BERT 擅长"理解"，却写不出新文本。GPT（Generative Pre-trained Transformer） 走完全相反的路：用解码器 + 语言模型目标预训练，模型只会一件事——预测下一个词。可正是这"最简单"的目标，配上超大参数量与海量数据，解锁了对话、写作、代码、推理等通用能力。这一章梳理 GPT-1 到 GPT-4 的演进逻辑、RLHF 对齐技术，以及 GPT 与 BERT 的本质差异。

上一章→本章→下一章 上一章拿到理解类王者 BERT。本章补齐生成式王者 GPT：解码器 + 语言模型 + 规模化 + RLHF。至此，NLP 的两大流派（理解/生成）与预训练范式全部讲完——文本与 LLM 的时代正式开始。
1① GPT 的基本思路：只做一件事，预测下一个词
要解决什么

BERT 要生成文本却"不会写"，GPT 怎么设计才能生成？

核心思路

GPT 的原则：用标准语言模型目标（自回归预测下一个 token）预训练一个解码器式 Transformer。

输入:  今天天气真 [??]
预测:  → "好"（下一个词）
  • 结构：只用 Transformer 的解码器（掩码自注意力），无编码器、无交叉注意力。
  • 训练：在海量网页/书籍上自监督学"下一个词"。
  • 生成：推理时不断把自己输出的词拼回去再预测下一个——这就是生成。

要点：没有为任何具体任务设计结构。翻译、问答、摘要……全是"预测下一个词"的换皮。GPT 用最朴素的目标，赌"会预测下一词，就会一切"。

坑在哪
现象原因 / 怎么办
以为 GPT 有编码器GPT 只用解码器；"GPT=通用预训练 Transformer"的名字里并不含编码器
把"预训练语言模型"和"BERT 的 MLM"混为一谈GPT 是自回归 LM（只看左文），BERT 是 MLM（看左右）；这是两条明确的路
2② GPT 的"免费午餐"：下游任务不用大改
要解决什么

BERT 每个任务要换头，GPT 怎么处理多任务？

核心思路

GPT 的迁移方式是任务提示化（Prompting）——把任务描述成"续写"：

  • 翻译："英语：Hello，中文："
  • 摘要："摘要这篇文章：[原文] 摘要："
  • 问答："Q：首都是哪？A："
  • 情感："这段影评情感是：[影评] 情感："

用特殊分隔符（如 翻译：、Q:）把任务封装成文本，GPT 直接续写就是答案——不需要设计任务头。GPT-2 时代这种能力还弱，到 GPT-3 的上下文学习（In-Context Learning）爆发：模型看一眼示例就能模仿任务（few-shot），甚至不需要更新参数。

这就是 GPT"通用"的本质：把一切任务翻译成"预测下一个词"。

坑在哪
现象原因 / 怎么办
以为 GPT 不能做分类用"情感：正面/负面"式提示即可续写出标签，照样能分类
few-shot 需要梯度更新上下文学习只在输入里放示例，不更新权重——这是它的神奇之处
3③ GPT-1 → GPT-2：从"能聊"到"无监督多任务"
要解决什么

GPT 1 和 2 各解决了什么，才有了后来的爆发？

核心思路

GPT-1（2018，1.17 亿参数）：

  • 提出"预训练 + 微调"的生成式路线（稍晚于 BERT，表现略逊）。
  • 贡献：验证解码器 + LM 也能学好语义表示。

GPT-2（2019，15 亿参数）：

  • 核心实验："Larger = Better"——大模型在未见过的任务上零样本小涌现。
  • 提出无监督多任务学习：不微调，靠提示直接完成任务。
  • 40GB WebText 语料；"语言模型就是无监督多任务学习器"。

转折点：从 GPT-2 起，"规模"成为主角——更多数据 + 更多参数 = 更强涌现能力。GPT2 的 15 亿参数在当时已算巨兽，为 GPT-3 的百倍规模铺路。

坑在哪
现象原因 / 怎么办
把 GPT-1 当成"弱 BERT"路线不同：BERT 做理解、GPT 做生成；不能以单一指标定胜负
忽略规模化的意义GPT-2 的真正遗产是"涌现"信号——这直接决定 OpenAI 加注千亿参数豪赌
4④ GPT-3：1750 亿参数与上下文学习
要解决什么

GPT-3 凭什么"一次训练、什么都会"？

核心思路

GPT-3（2020）三大动作：

  1. 规模：1750 亿参数（GPT-2 的 117 倍），45TB 语料。
  2. 上下文学习（In-Context Learning）：
  • few-shot：输入里放 2-3 个示例，模型照做。
  • zero-shot：连示例都不给，直接提示。
  • 不更新任何参数——能力从"预训练知识 + 示例模式"中涌现。
  1. 通用性：写代码（Codex）、翻译、数学题、新闻生成……同一模型直接上岗。

关键洞察："预测下一个词"在千亿规模下，自动涌现出推理、模仿、泛化能力——这不是设计出来的，是规模喂出来的。

坑在哪
现象原因 / 怎么办
以为 few-shot 是微调是提示词里的示例，模型权重完全冻结——"上下文学习"≠"梯度学习"
迷信 GPT-3 全知全能它有幻觉（编造事实）、偏见、逻辑错误，能力涌现但不完美
5⑤ 对齐技术 RLHF：让模型听人话
要解决什么

GPT-3 会写但可能说错话、有毒、不听话——怎么把它"调教"成助手？

核心思路

RLHF（基于人类反馈的强化学习） 三步走：

①监督微调 SFT: 人工写优质问答，让模型先模仿
②奖励模型 RM:  人类对多个回答排序 → 训练打分模型
③强化学习 PPO: 用 RM 当"裁判"，优化模型让它答得更好
  • 步骤 1 让模型有基本对话能力。
  • 步骤 2 把"人类偏好"变成可优化的奖励信号。
  • 步骤 3 用强化学习把偏好"内化"进模型。

效果：模型更愿意遵循指令、拒绝有害请求、语气亲和。ChatGPT 的高质量体验来自这一步——不是模型更"聪明"，而是更"对齐"。

坑在哪
现象原因 / 怎么办
把 SFT 当 RLHF 全部SFT 只是第一步；RLHF 的核心价值在 RM + PPO 的偏好优化
以为 RLHF 提升知识量它改变的是行为/安全/风格，不是知识水平——知识靠预训练
写"RLHF=人类反馈"就完事完整三阶段（SFT→RM→PPO）才算讲清，缺一都不叫 RLHF
6⑥ GPT-4 与多模态：工程与能力的全面跃升
要解决什么

GPT-4 相对 GPT-3 到底"新"在哪？

核心思路

GPT-4（2023）的关键事实与升级：

  • 规模与数据：未公开具体参数；更大训练量 + 更高质量数据（重保真、重清洗）。
  • 多模态（Multimodal）：输入支持图像（看懂图表、照片、草图），输出仍是文本。
  • 能力提升：复杂推理、长文、考试（美国律师/医师资格考过线）、代码水平显著超过 GPT-3.5。
  • 安全对齐强化：更稳的安全护栏与拒绝机制。

意义："泛化能力随规模上台阶"被再次验证；多模态标志着"文本预训练"向"世界理解"演进——给模型看世界，它才对世界有常识。

坑在哪
现象原因 / 怎么办
以为 GPT-4 只是"更大 GPT-3"数据质量、多模态、对齐三条线同时升级，是系统工程不是单纯堆参
夸大 GPT-4 的可靠性仍有幻觉与错误，尤其多模态图像细节识别会出错
7⑦ Hugging Face 使用 GPT：从加载到生成
要解决什么

自己机器上怎么把 GPT 模型跑起来生成一句话？

核心思路

用 transformers 加载 GPT-2（本地可跑的入门选择）：

from transformers import GPT2LMHeadModel, GPT2Tokenizer

tokenizer = GPT2Tokenizer.from_pretrained("gpt2")
model = GPT2LMHeadModel.from_pretrained("gpt2")

prompt = "Once upon a time"
inputs = tokenizer(prompt, return_tensors="pt")
out = model.generate(
    **inputs, max_new_tokens=50,
    do_sample=True, top_p=0.9,
)
text = tokenizer.decode(out[0], skip_special_tokens=True)
print(text)

要点与参数：

  • LMHeadModel 自带语言模型头，generate 封装自回归生成。
  • do_sample=True 允许随机采样（而非贪心），top_p 控制多样性。
  • max_new_tokens 限制生成长度。

这就是"下载权重 → 生成文本"的标准姿势；换成 gpt2-medium/gpt2-large 只需改名字符串。

坑在哪
现象原因 / 怎么办
本地直接加载 GPT-4 权重GPT-4 不公开权重，本地只有开源替代（LLaMA/Qwen 等）；示例用 gpt2 讲原理
不用 generate 手写循环手写容易漏采样/停止逻辑，用官方 generate 更稳
8⑧ GPT 与 BERT：一张表看懂两大路线

预训练时代最经典的二选一，到底差在哪？
